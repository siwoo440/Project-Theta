# 21일차 - 도시 지도 씬 및 장소 기반 한 판 구조 구현

## 이번 일차의 목표

20일차에 기획서를 다시 보며 점수를 매겼을 때 가장 낮았던 영역은 **스테이지 · 목표 다양성(3점)** 과 **반복 플레이(3점)** 였다.
게임이 "학교 4층 한 곳을 깨면 끝"이었기 때문이다.

그래서 개발을 잠시 멈추고 기획으로 돌아가 다음을 정했다 (`Design/` 폴더).

- **부록 B** — 판타지 지역 대신 **현실 장소 8곳의 해안 도시** (기업 연수원 · 해변가 · 지하철 환승역 · 헬스장 · 야시장 · 쇼핑몰 · 오피스 타워 · 루프탑 클럽)
- **부록 C** — 장소마다 어울리는 방해 세력 27종, 특수 능력 11종

21일차는 그 기획을 올릴 **뼈대를 만드는 날**이었다.

1. 장소를 **설정표 하나로 갈아 끼우는 틀**
2. 한 판을 **5구역**으로 늘리고, 구역마다 **도시 지도(Map 씬)에서 다음 장소를 고르게** 하기
3. 레벨 · 카드가 **구역을 넘어 이어지게** 하기

장소별 지형 · 환경 규칙 · 방해 세력은 22일차부터 채운다. 오늘 연수원을 뺀 7곳은 **색 · 층 수 · NPC 수 · 시간만 다른 임시 장소**다.

## 기획 결정

### 시작 구역: 기업 연수원

처음 제안한 대학 캠퍼스는 삭제했다. 고등학교 설정은 이 게임의 성인 콘텐츠 방향과 맞지 않아 쓰지 않고,
지금의 층 · 복도 · 계단 구조를 그대로 살릴 수 있으면서 등장인물이 모두 성인임이 분명한 **기업 연수원**으로 정했다.

### 고르는 방식: 구역마다 지도에서 선택

세 가지 안 중에서 골랐다.

| 안 | 내용 | 결과 |
| --- | --- | --- |
| **구역마다 지도에서 선택** | 5구역 한 판. 구역을 끝낼 때마다 지도로 돌아와 다음 장소를 고름 | **채택** |
| 장소 하나 = 스테이지 하나 | 해금된 장소를 아무거나 골라 1구역만 플레이 | - |
| 출발 전에 경로 전체 선택 | 출격 전에 가운데 3곳을 미리 확정 | - |

무작위로 정해지는 경로보다 **플레이어가 경로를 짜는 선택**이 반복 플레이의 재미를 더 크게 만든다고 판단했다.

## A. 씬 흐름

```
Boot → MainMenu → Hub → Map → Stage → Map → Stage … → Hub
                         │                          ↑
                         └── 판 포기 ────────────────┘
```

| 전환 | 허용 | 저장 |
| --- | --- | --- |
| Hub → Map | 출격 | - |
| Hub → Stage | **막음** (반드시 지도를 거친다) | - |
| Map → Stage | 출발 | - |
| Map → Hub | 판 포기 | - |
| Stage → Map | 구역 클리어, 판이 이어짐 | **저장** |
| Stage → Hub | 실패 또는 마지막 구역 클리어 | 저장 |

**Stage → Map에서도 저장한다.** 구역을 클리어할 때마다 그 구역의 정기를 확정해서,
다음 구역에서 실패해도 이미 클리어한 구역의 보상은 남는다 (기획서 24장 "확정 회수한 정기 일부 보존").

### Map 씬 파일

기존 `Hub.unity`를 복사해 새 GUID를 붙이고 `EditorBuildSettings`에 Hub와 TestStage 사이로 등록했다.
이 프로젝트의 다른 씬처럼 **씬 파일은 비어 있고** 내용은 `SceneScreenBootstrap`이 런타임에 `MapScreen`을 붙여 만든다.

## C. 한 판 경로 (`Run/RunRoute.cs`)

### 규칙

```
1구역  기업 연수원 (고정)
2구역  낮 · 저녁 장소 중 2곳 제시 → 선택
3구역  저녁 · 밤 장소 중 2곳 제시 → 선택
4구역  저녁 · 밤 장소 중 2곳 제시 → 선택
5구역  루프탑 클럽 (고정)
```

- 같은 장소는 한 판에 한 번만 간다
- **시간은 거꾸로 흐르지 않는다.** 밤 장소에 간 뒤에는 저녁 장소를 제시하지 않는다
- 후보는 **판 시드 + 구역 번호**로 정해진다. 지도를 다시 열어도 같은 후보가 나온다

규칙이 막다른 길을 만들지 않는지 **시드 300개 × 두 가지 선택 방식**으로 끝까지 경로를 만들어 확인했다.
혹시 장소 표를 자산으로 바꿔 후보가 비는 경우에는 안 간 장소 전체로 넓혀 게임이 멈추지 않게 했다.

### 판 정보 `RunSession`

구역마다 스테이지 씬을 **다시 불러온다.** 한 씬 안에서 장소를 지우고 다시 짓는 방식은
모든 오브젝트를 구역 루트 아래로 옮기는 대공사가 필요하고, 18일차에 정리한 등록 목록 · 정적 이벤트가 섞일 위험이 컸다.
씬을 다시 불러오면 허브 재출격과 **이미 검증된 같은 경로**를 탄다.

대신 구역을 넘어 이어져야 하는 값은 `GameSession`이 들고 있는 `RunSession`에 둔다.

| 값 | 내용 |
| --- | --- |
| 시드 · 방문한 장소 · 구역 기록 | 경로와 지도 표시 |
| `RunLevelState` · `RunUpgradeState` | **레벨 · 고른 카드 그 자체.** 복사하지 않고 같은 객체를 다음 구역의 `RunProgression`이 이어받는다 |
| 시작 계약 선택 여부 | 첫 구역에서만 시작 계약 카드 |
| 남은 카드 선택 수 | 클리어하는 순간 오른 레벨의 카드는 다음 구역 시작 때 이어서 고른다 |

구역 기록은 한 번만 남고, 실패하거나 5구역을 끝내면 판이 끝난다.

| 요소 | 내용 |

| 상태 | **선택 가능**(시간대 색 테두리 + 뒤에서 맥동하는 빛) · **선택됨**(금색) · **완료**(어두운 금색) · **잠김**(회색, 클럽은 "최종") |
| 길 | 기획서 B.2의 연결을 선으로 그림. 지금은 보기용이며 이동 제약은 없음 |
| 경로 줄 | 지나온 구역은 "장소 랭크", 지금 구역은 선택 중인 장소, 남은 칸은 `?` |

| 조작 | 클릭 또는 **숫자 키 1 · 2**로 선택, **Enter**로 출발 |
| 판 포기 | **두 번 눌러야** 포기 (3초 안에). 실수 방지 |

후보가 한 곳뿐인 1구역 · 5구역은 들어오자마자 미리 선택되어 있다.
판 없이 Map 씬을 바로 재생하면 새 판을 만들어 시작한다.

## E. 스테이지를 장소 기반으로

| 부분 | 바뀐 것 |
| --- | --- |
| 부트스트랩 | 지도에서 고른 장소를 읽어 `LocationContext`에 둠. 판 없이 TestStage를 바로 재생하면 연수원 구역 1로 시작 (`GameSession.EnsureRunForStage`) |
| 건물 | 층 색조에 장소 색을 곱함 (`SchoolHallwayPrototypeBuilder.Build(floorCount, tint)`) |
| NPC | 층별 인원 × 장소 밀도. 등급 구성에 **구역 번호를 더해** 뒤 구역일수록 고급 NPC가 섞임 |
| 목표 | `StageSessionController.ApplyObjective(제한 시간, 목표 정기)` |
| 경쟁자 | 장소에 경쟁자가 있을 때만 배치. 시작 층은 장소 층 수 안으로 자름 (1층짜리 장소에서 2층 금태양이 허공에 서지 않게) |
| 시간대 | `TimeOfDayOverlay` — 카메라 배경색 + 화면 전체 얇은 색막(저녁 주황 13% · 밤 남색 34%). 월드 연출(40) · HUD(50) 아래 30번이라 글자는 어두워지지 않음 |
| HUD | 우상단 "구역 2/5 · 해변가 · 낮", 층 표시 "백사장 1F" |
| 튜토리얼 | **연수원에서만** 안내. 다른 장소에서는 세이브의 튜토리얼 완료 기록도 건드리지 않음 |
| 결과 화면 | 제목 "구역 2/5 · 해변가 — CLEAR", 버튼 **"지도로 (다음 구역)"** 또는 **"허브로"**. 마지막 구역이면 "한 판 종료 · 5구역 · 계약 정기 +N" |

## 판단한 것

### 1. 오늘은 흐름만, 내용은 22일차부터

장소 7곳에 지형 · 규칙 · 적까지 넣으면 하루에 끝나지 않고, 무엇이 흐름 문제이고 무엇이 장소 문제인지 섞인다.
오늘은 **"5구역 한 판이 처음부터 끝까지 이어지는가"** 하나만 확인할 수 있게 범위를 잘랐다.

### 2. 계획에서 빠진 것

| 계획 | 처리 |
| --- | --- |
| 구역 사이 지하철 이동 연출 | 도시 지도 화면이 그 역할을 대신해서 만들지 않음 |
| 연수원 쉬는 시간 종 · 자습실 | 22일차 경계도 시스템과 함께 |
| 연수원 외형 | 이름 · 층 표시만 바꿈. 복도 그림은 아직 학교 모양 |

### 3. 알아 둘 동작

- 치트와 디버그 게임 속도는 **구역이 바뀔 때마다 꺼진다**
- 허브 통계의 플레이 · 클리어 횟수는 **구역 단위**로 오른다. 판 단위 통계는 27일차 통합 때 정리한다
