# 37일차 - 배경음악 · 효과음(임시 음원) · 허브 저장 칸 선택 · 타이틀로 경고 구현

## 이번 일차의 목표

36일차에 남은 **"배경음악 · 효과음"**을 다뤘다. 정식 음원 파일이 없어 **임시 음원을 직접 만들어** 먼저 연결했다. 여기에 허브 저장 · 타이틀로 버튼 요청을 함께 반영했다.

- 게임 전체에 배경음악이 없었고, 효과음은 UI 소리 몇 개뿐이었다.
- 목표 달성 뒤 추격 · 위기 · 탈출 같은 중요한 순간에 소리 신호가 없었다.
- 허브 `저장`은 지금 칸에만 저장됐고, `타이틀로`는 한 번 누르면 바로 나갔다.

## A. 임시 음원 (`Tools/generate_temp_audio.py`)

```
python Tools/generate_temp_audio.py        # 음악 + 효과음
python Tools/generate_temp_audio.py sfx    # 효과음만
```

- 기존 임시 자산 생성기(`generate_temp_assets.py`)의 wav 쓰기 · meta 함수를 가져다 쓴다.
- 이름에서 정한 시드를 써서 **다시 만들어도 같은 파일**이 나오고, 이미 있는 `.meta`의 GUID는 그대로 둔다.
- 음악은 22,050Hz · 4마디이고, 긴장 겹은 정확히 1마디 길이라 곡과 박자가 맞는다. 음악 meta는 압축한 채 메모리에 두는 Vorbis(미리 읽지 않음 · 백그라운드 로드)로 둔다.
- 음악 24개 약 11MB, 효과음 12개.

## B. 배경음악 재생 (`Presentation/MusicLogic`, `Presentation/MusicPlayer`)

- `MusicPlayer`는 첫 씬 뒤 하나만 만들어져 씬을 넘어 산다. 소스 A · B(크로스페이드)와 긴장 소스 3개를 쓴다.
- 곡 고르기: 씬 이름 + 지금 장소 + 엔딩 재생 중인지 → `MusicLogic.GetTrack`. 같은 곡이 이어지는 화면끼리는 끊기지 않는다.

| 긴장 단계 | 조건 | 긴장 겹 음량 |
| --- | --- | --- |
| 평온 | 기본, 도전이 끝났을 때 | 0 |
| 추격 | 목표 달성 뒤 추격 중 | 0.6 |
| 위기 | 남은 시간 15초 이하 또는 체력 30% 이하 | 1.0 (곡 높이 ×1.05) |

- 긴장 겹은 0.8초에 걸쳐 커지고 줄어든다. 곡과 50ms 넘게 어긋나면 다시 맞춘다.
- 심야 모드에서는 곡 높이를 ×0.94로 살짝 낮춘다.
- 대사 창이 열려 있으면 음악을 60%로 줄인다.
- 음량은 설정의 음악 음량을 따른다. 설정 창 문구를 "(임시 음원 · 정식 음악으로 교체 예정)"으로 바꿨다.

## C. 효과음 연결

- `GameAudio`에 효과음 12개와 높이를 바꿔 내는 `PlayPitched`를 추가했다. 높이를 바꾸는 소리는 따로 둔 소스로 내서 다른 소리에 영향이 없다.
- 대사 창 · 허브 서큐버스 말풍선: 글자가 나올 때 두 글자마다 소리가 난다(공백은 건너뜀).
  - 높이: 나 1.25 · 라이벌 1.1 · 해설 0.9 · 그 외는 이름에서 정한 값.
- 연결한 곳: `StageVfxDirector`(추격 시작 · 위기 경고), `ExitBanner`, `StageResultPanel`, `AchievementToast`, `HubScreen`, `MapScreen`.

## D. 허브 저장 칸 선택 (`UI/SaveSlotPanel`, `Save/SaveSlotLogic`, `Core/GameSession`)

- 허브 `저장`을 누르면 메인 메뉴와 같은 저장 칸 창이 **"저장 · 저장할 칸"**으로 열린다(`SaveSlotMode.Save`).

| 칸 | 버튼 | 누르면 |
| --- | --- | --- |
| 지금 칸(초록 "지금 칸") | `여기에 저장` | 바로 저장 |
| 빈 칸 | `이 칸에 저장` | 바로 저장 |
| 기록이 있는 다른 칸 | `덮어쓰기` | "한 번 더 누르면 덮어씀", 3초 안에 다시 누르면 저장 |

- `GameSession.SaveToSlot`: 고른 칸에 저장하고 **그 칸을 지금 칸으로 바꾼다.** 이후 자동 저장도 그 칸으로 간다.
- 저장 문구: "3번 칸에 저장했습니다 · 이제 3번 칸으로 플레이 · 시각". 같은 칸이면 뒷부분 없이 나온다.
- 창을 열 때 열려 있던 허브 창은 닫는다.

## E. 타이틀로 경고 (`UI/HubScreen`, `UI/HubRoomLogic`)

- 첫 번째 누름: 버튼이 붉게 "한 번 더 누르면 나감"으로 바뀌고 경고음이 난다.
  - 아래 띠에 붉은 글자로 "타이틀로 나갈까요? 마지막 저장 {시각} · 한 번 더 누르면 나갑니다"가 뜬다.
  - 저장한 적이 없으면 "아직 저장한 적이 없습니다"로 나온다.
- 3초 안에 다시 누르면 메인 메뉴로 간다. 3초가 지나면 버튼이 원래대로 돌아온다.
- 경고 문구가 길어 아래 띠 문구 칸을 두 줄까지 쓰도록 넓혔다.
