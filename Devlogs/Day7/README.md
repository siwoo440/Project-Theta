# Project θ 개발 일지 — 7일차

## 개발 목표

1~6일차에 구현한 핵심 시스템을 하나의 플레이 루프로 통합하고, 폭주 NPC에게 붙잡혔을 때 직접 탈출하는 포획 미니게임을 추가했다.

7일차 핵심 흐름은 다음과 같다.

```text
NPC 최면
→ 동행
→ 정기 지속 생산
→ 충동 상승
→ 폭주
→ 플레이어 접촉
→ 포획 상태
→ 좌/우 클릭 교대 입력
→ 탈출 또는 누적 피해 10
→ 회복 후 동행 재개
→ 정기 200 달성
→ CLEAR
```

## 포획 상태 추가

폭주 NPC가 플레이어에게 접촉하면 기존의 즉시 피해 방식 대신 Capturing 상태로 전환한다.

폭주 상태 흐름:

```text
Preparing
→ Rampaging
→ Capturing
→ Recovering
```

포획이 시작되면 플레이어 이동, 대시, 최면 입력을 잠그고 탈출 미니게임에 집중하도록 구성했다.

## 포획 이미지 연출

포획 상태 전용 이미지를 추가했다.

```text
Assets/_Project/Resources/Capture/PlayerGrabOverlay.png
```

포획 중 화면 중앙에 이미지를 표시하고 배경을 어둡게 처리한다.

좌클릭 또는 우클릭을 올바르게 입력할 때마다 이미지가 입력 방향에 맞춰 좌우로 짧게 흔들린 뒤 중앙으로 복귀한다.

## 좌/우 클릭 교대 탈출 미니게임

플레이어는 다음 순서로 좌클릭과 우클릭을 번갈아 입력한다.

```text
좌클릭
→ 우클릭
→ 좌클릭
→ 우클릭
→ 반복
```

초기 수치:

- 탈출 게이지 최대: 100
- 올바른 입력 1회: +12
- 같은 버튼 연속 입력: 증가 없음
- 포획 시작 시 첫 입력: 좌클릭

올바른 입력으로 탈출 게이지가 100에 도달하면 즉시 포획 상태에서 빠져나온다.

## 포획 중 체력 피해

기존 폭주 접촉 피해 -25를 제거하고 지속 피해 방식으로 변경했다.

초기 수치:

- 피해 1회: HP -1
- 피해 간격: 0.4초
- 포획 1회 최대 누적 피해: 10

즉, 탈출 입력을 하지 않더라도 누적 피해가 10에 도달하면 자동으로 포획이 종료된다.

```text
포획 시작
→ HP -1
→ HP -1
→ ...
→ 누적 -10
→ 자동 해제
```

플레이어가 빠르게 탈출할수록 실제로 받는 피해가 감소한다.

## 폭주 포획 보상

폭주 NPC에게 붙잡히는 순간 정기 +10을 지급한다.

한 번의 포획에서 보상은 한 번만 지급된다.

```text
폭주 접촉
→ 정기 +10
→ Capturing
```

## 플레이어 입력 잠금 구조 개선

PlayerSideViewController에 입력 잠금 기능을 추가했다.

포획 중:

- 이동 불가
- 대시 불가
- 최면 불가
- 좌/우 탈출 입력만 처리

스테이지가 종료되었을 때도 같은 입력 잠금 구조를 사용한다.

## 스테이지 종료 처리

정기 200 달성, 제한시간 종료, 체력 0 등으로 스테이지가 끝나면 진행 중인 게임 시스템을 정리한다.

종료 시:

```text
플레이어 이동/대시 잠금
→ 최면 입력 중지
→ 진행 중 포획 종료
→ 폭주/충동 중지
→ Follower 이동 중지
→ 일반 NPC 이동 중지
→ 회수 지점 중지
→ Rigidbody2D 속도 0
```

CLEAR 또는 FAILED 이후에도 게임이 계속 진행되는 상태 충돌을 줄였다.

## 회수와 폭주/포획 충돌 처리

회수 지점에 진입한 Follower는 회수 처리를 우선하도록 정리했다.

회수되는 NPC가 폭주 또는 포획 관련 상태를 가지고 있으면 해당 상태를 먼저 취소한 뒤 Follower 목록에서 제거한다.

```text
회수 판정
→ 폭주/포획 상태 취소
→ Follower 제거
→ NPC 비활성화
→ 정기 +5
```

## 다수 Follower 대열 개선

Follower가 많아질수록 뒤쪽으로 지나치게 길게 늘어지는 문제를 줄이기 위해 Compact Formation을 적용했다.

기존 2행 기반 대열 대신 기본 3행 단위로 배치한다.

10명의 Follower 기준으로 약 4개 열 안에 배치되어 플레이어 뒤쪽에 더 조밀한 군집을 형성한다.

기존의 개인별 위치 편차, Wander, Soft Separation은 유지한다.

## 유지도 계산 개선

기존에는 Follower 유지도를 플레이어와의 직접 거리로 계산했기 때문에 슬롯 번호가 큰 NPC가 정상적인 대열 위치에 있어도 유지도가 감소할 수 있었다.

7일차부터는 각 NPC가 배정받은 Formation 목표 위치와의 거리를 기준으로 유지도를 계산한다.

```text
NPC ↔ 플레이어 거리
```

대신:

```text
NPC ↔ 자신의 Formation 목표 위치 거리
```

를 사용한다.

이를 통해 많은 NPC를 동행시켰을 때 뒤쪽 Follower가 구조적으로 불리해지는 현상을 완화했다.

## 정기 지속 생산 Tick 통합

6일차에는 각 Follower가 개별 타이머로 정기를 생산했다.

7일차에서는 StageSessionController가 동행 인원 수를 기준으로 1초마다 한 번에 정기를 지급하도록 통합했다.

```text
동행 1명 → +1 / sec
동행 5명 → +5 / sec
동행 10명 → +10 / sec
```

여러 NPC의 생산 타이밍이 흩어지지 않고 동일한 1초 Tick에서 처리된다.

포획 입력과 Compact Formation용 EditMode 테스트를 추가했다.

- 요구 입력과 실제 입력 일치 판정
