# 43일차 — 프롤로그·스토리 1~4 게임 내 반영

---
## 구현

- 계약 프롤로그부터 스토리 4까지 11개 장면을 고정 ID와 선행 완료 조건으로 등록했다.
- 프롤로그에 주인공의 자발적인 계약 선택을 추가하고 선택 결과가 기존 스토리 저장 구조에 남도록 연결했다.
- 첫 계약 임무를 특정 지역에 고정하지 않고 플레이어가 선택한 첫 장소에서 시작하도록 구현했다.
- 인지저하 마법 설명을 제한 시간·경계도 안내와 연결했다.
- 실제 최면 성공·회수 확정 사건에서 첫 최면→동행→회수 안내가 순서대로 재생되도록 구현했다.
- 동행자 탈취와 재최면 사건을 경쟁자 쟁탈·재탈환 학습 장면에 연결했다.
- 첫 임무 클리어 후 르미아 조우, 경쟁 임무 후 리엘라 관계 변화가 순서대로 이어지도록 구성했다.
- 스토리 4 후일담 완료 후 기존 지역 이야기 장면이 열리도록 초반·지역 구간을 분리했다.
- 스테이지 사건 대화는 다른 대화창과 겹치지 않도록 대기열에서 순차 재생하고 완료 상태를 즉시 저장하도록 연결했다.
