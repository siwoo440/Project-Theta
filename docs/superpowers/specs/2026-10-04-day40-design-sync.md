# 40일차 기획·코드 동기화 설계

## 목표

- 저장 장소 ID `0`을 유지하면서 시작 지역의 표시와 적 구성을 고등학교 기준으로 바꾼다.
- 교사는 걷기를 허용하고 달리기·대시·최면만 감지한다.
- 생활지도부장은 최면을 발견하면 시전을 끊고 밀쳐내며 잠시 재시전을 막는다.
- 고등학교에는 금태양만 경쟁자로 등장하도록 한다.

## 호환성

- `LocationId.TrainingCenter = 0`, `DisruptorKind.TrainingAssistant = 0`, `DisruptorKind.HrEvaluator = 1`은 직렬화 호환성을 위해 내부 이름과 숫자를 유지한다.
- 사용자에게 보이는 명칭만 `고등학교`, `교사`, `생활지도부장`으로 동기화한다.

## 검증 기준

- 시작 지역 ID와 기존 저장 해석이 유지된다.
- 장소·안내·스토리·업적의 현재 표시 문구에서 기업 연수원 표현이 제거된다.
- 교사와 생활지도부장 수치가 최신 기획 값과 일치한다.
- 고등학교 경쟁자 배치에서 인기남이 제외된다.
- 순수 로직 테스트와 전체 컴파일 검증이 통과한다.
