# 20일차 - 디버그 패널 제작 및 UI 꾸미기

## 이번 일차의 목표

18·19일차에 수치를 몇 번 고쳤다. "집중력이 너무 빨리 준다", "최면이 느리다" 같은 **느낌**을 근거로 고쳤고,
고칠 때마다 재생을 멈추고 → 자산을 열어 값을 바꾸고 → 1층부터 다시 올라가야 했다.

그리고 F1 디버그 창은 15일차 이전에 만든 IMGUI 글자 목록 그대로였다. 볼 수만 있고 만질 수는 없었다.

20일차는

1. **F1 창을 Canvas 디버그 패널로 새로 만들어** 보고 · 바꾸고 · 상황을 만들고 · 기록하게 하고
2. **HUD · 카드 · 결과 · 허브를 꾸미는 날**이었다.

## A. 디버그 패널

`UI/Debug/DebugPanel.cs` — F1로 열고 닫는다. 화면 오른쪽에 붙는 폭 480 창이다.

```
┌──────────────────────────────────────┐
│ ◆ DEBUG          60 fps  ×1     F1 × │
├──────────────────────────────────────┤
│ [상태]  수치   치트   기록           │
├──────────────────────────────────────┤
│ ▶ 판 진행                             │
│   ...                                │
```

| 탭 | 내용 |
| --- | --- |
| **상태** | 층 · 경과/남은 시간 · 레벨/경험치 · 정기 · 체력 · 집중력 가속 배율 · 동행 · 최면 배율 · 조준 중인 NPC(초당 최면량) · 경쟁자(층, 같은 층이면 초록) · 최고 충동 · 폭주 · 포획 |
| **수치** | 밸런스 수치 16개를 슬라이더로 조정. 묶음별 되돌리기, 전부 되돌리기, 자산에 저장(에디터 전용) |
| **치트** | 층 이동 · 체력/집중력 채우기 · 무적 · 집중력 무한 · +50 XP · 레벨업 · +100 정기 · 이 층 NPC 전부 최면 · 가까운 동행 폭주 · 동행 충동 0 · 게임 속도 ×0.25~×2 |
| **기록** | 층별 시간 막대 · 최면/되찾기/빼앗김/회수/폭주/포획/힘겨루기 횟수 · 집중력 0이었던 시간 비율 · 레벨업 시각 · 기록 폴더 열기 |

### 설계에서 신경 쓴 것

- **처음 열 때 만든다.** 스테이지 시작 시간에 UI 조각 수백 개를 미리 만들지 않는다
- **1초에 10번만 갱신한다.** 디버그 글자 때문에 프레임이 떨어지면 안 된다
- **에디터 · 개발 빌드에서만 생성한다** (`Debug.isDebugBuild`). 정식 빌드에는 치트가 없다
- 결과 화면(200)보다 위(500)에 뜬다. 판이 끝난 뒤에도 기록을 볼 수 있다

### 패널 위 클릭이 게임으로 새지 않게

최면(좌클릭)과 파동(우클릭)은 uGUI 이벤트가 아니라 **마우스 상태를 직접 읽는다.**
그래서 슬라이더를 끄는 동안 최면이 같이 나갔다.

`Core/DebugCheats.cs`에 `PointerGuard.IsOverOverlay`를 두고,
패널이 매 프레임 "마우스가 패널 사각형 안인가"를 적는다. `HypnosisCaster`와 `HypnosisWaveCaster`는 이 값이 true면 입력을 무시한다.

버튼을 누른 뒤에는 **선택을 푼다.** 선택된 버튼은 스페이스·엔터로 다시 눌리는데, 스페이스는 대시 키다.

## B. 수치 탭 — 자산 원본을 건드리지 않는다

`Balance/BalanceTuning.cs`

### 문제

`StageBalanceDatabase.Apply`는 자산 안의 값 묶음을 **복사하지 않고 그대로** 주입한다.
그 객체를 슬라이더로 바꾸면, 에디터에서는 자산이 메모리에서 바뀐 채로 남고 다른 이유로 자산이 저장될 때 **디스크에까지 써진다.**
"저장 안 눌렀는데 자산이 바뀌어 있다"는 버그가 된다.

### 해결

```
처음 슬라이더를 움직이는 순간
    기준  ← 지금 주입된 값 (자산 원본)
    주입  ← 기준.Clone()        ← 이후 모든 변경은 여기에만
```

| 동작 | 결과 |
| --- | --- |
| 되돌리기(묶음) | 그 묶음 수치만 기준 값으로 |
| 전부 되돌리기 | 주입을 기준(자산 원본)으로 복구. 자산이 없던 경우는 `null`로 복구 |
| 자산에 저장 | 자산 값 ← 지금 값의 복사본, `SetDirty` + `SaveAssetIfDirty`, 저장된 값이 새 기준 |
| 재생 종료 | `BalanceBootstrap.Reset`이 편집 상태를 지우고 다음 재생이 자산을 새로 읽음 |

바꾼 값은 **금색 + `•`** 로 표시되고, 아래에 "바뀐 값 N개"가 뜬다.

### 조정 가능한 수치 16개

| 묶음 | 수치 |
| --- | --- |
| 최면 | 일반 최면 배율 · 집중력 가속 · 체인 범위 |
| 집중력 · 파동 | 최면 중 초당 소모 · 초당 회복 · 파동 비용 · 파동 재사용 |
| 성장 | 경험치 기본 · 레벨당 증가 · 최면 경험치 · 새 층 경험치 |
| 위험 · 회수 | 충동 증가 배율 · 묶음 회수 대기 · 콤보 유지 |
| 연출 | 흔들림 세기(중) · 멈칫 시간 |

수치 하나는 `TuningParameter`(이름, 범위, 정수 여부, 읽기·쓰기 함수)로 표현한다. 새 수치는 목록에 한 줄만 추가하면 된다.

### 자산으로 옮긴 값

집중력 소모·회복은 `PlayerFocus` 컴포넌트 안에 박혀 있어서 조정할 수 없었다. 19일차에 문제가 된 바로 그 값이다.

| 새 항목 | 값 | 전 위치 |
| --- | ---: | --- |
| `FocusHypnosisDrainPerSecond` | 6 | `PlayerFocus._hypnosisDrainPerSecond` |
| `FocusRecoveryPerSecond` | 14 | `PlayerFocus._recoveryPerSecond` |
| `ImpulseBuildScale` | 1 | 새로 추가 (충동 증가 전체 배율) |

**값은 그대로 옮겼다.** 밸런스는 바뀌지 않았다.

## C. 치트 탭 — 원래 길을 탄다

치트는 **게임의 원래 처리 경로를 그대로 탄다.** 치트로 만든 상황에서 본 문제가 실제 플레이에서도 같은 문제여야 하기 때문이다.

| 치트 | 탄 경로 |
| --- | --- |
| 층 이동 | `FloorTransitionController.DebugTravelTo` → 계단 이동과 같은 `TravelTo` (동행 인계, 경쟁자 조우, 첫 방문 경험치, 페이드) |
| 이 층 NPC 전부 최면 | `HypnosisCaster.DebugClaim` → 실제 최면 성공과 같은 `ClaimForPlayer` (점수, 경험치, 하트 연출, 동행 합류, 인원 초과 시 풀림) |
| 가까운 동행 폭주 | `ImpulseMeter.DebugFillImpulse` → 충동만 채우고 폭주 준비 전환은 평소 흐름에 맡김 |
| 레벨업 | 다음 레벨까지 필요한 경험치를 **경험치 배율 카드로 나눠서** 준다. 한 번에 두 레벨이 오르지 않는다 |
| 무적 · 집중력 무한 | `PlayerHealth.TakeDamage`, `PlayerFocus.Update`가 켜져 있는지만 본다 |
| 게임 속도 | `GameplayPause.SetDebugSpeed` → `TimeScaleLogic.Resolve`에 곱함 |

### 게임 속도와 카드 화면

19일차 규칙 "완전 정지가 항상 이긴다"를 지키려고 속도는 **마지막에 곱한다.**
`0(카드 화면) × 2 = 0`이라 속도를 올려도 카드 화면은 풀리지 않는다.

### 치트가 새지 않게

- 치트·게임 속도는 **판마다 꺼진 채로 시작**한다 (부트스트랩에서 초기화)
- 디버그 패널이 사라질 때(스테이지를 떠날 때) 속도를 1로 되돌린다. ×0.25가 허브로 새지 않는다
- 치트를 한 번이라도 쓰면 `DebugCheats.UsedThisRun` → 판 기록에 **"치트"** 로 남는다. 그 판 숫자로 밸런스를 판단하지 않기 위해서다

## D. 판 기록

`Run/RunStats.cs` (순수 계산) · `Run/RunStatsRecorder.cs` (모으는 쪽)

게임 규칙은 건드리지 않았다. 19일차 알림(`StageMoments`)과 레벨·층 알림을 **듣기만** 한다.
빼앗김 알림(`StageMoments.FollowerStolen`)만 새로 추가해 `OpponentControllerBase.TryDetachFromPlayer`에서 보낸다.

| 기록 | 방법 |
| --- | --- |
| 층별 시간 | 매 프레임 `deltaTime`을 지금 층에 더함. 카드 화면은 timeScale 0이라 자연히 빠짐 |
| 집중력 0 시간 | 같은 방법. 19일차 집중력 개편이 의도대로 도는지 보는 숫자 |
| 레벨업 시각 | 레벨마다 한 줄. 한 번에 두 레벨이 올라도 두 줄 |
| 횟수 | 최면 · 되찾기 · 빼앗김 · 회수 인원/정기 · 폭주 준비/회피 · 포획 · 힘겨루기 승리 |

판이 끝나면 `persistentDataPath/RunLogs/날짜_시간.json`에 남긴다.
그때의 결과 · 난이도 · 핵심 수치(최면 배율, 집중력 가속·소모, 충동 배율) · 수치 조정 여부를 함께 적어 **판끼리 비교**할 수 있게 했다.
기록 파일은 개발 빌드에서만 쓰고, 쓰기에 실패해도 결과 화면을 막지 않는다.

## E. UI 꾸미기

새 그림 파일 없이 19일차 연출 그림(`SoftCircle`, `Spark`, `Pillar`)을 재사용했다.
장식은 전부 클릭을 받지 않고, 카드 화면처럼 시간이 멈춘 곳에서도 움직이도록 **실제 시간(unscaled)** 으로 움직인다.

`UI/Framework/UiDecor.cs`

| 조각 | 내용 |
| --- | --- |
| `UiHoverEffect` | 마우스를 올리면 1.035배로 커지고, 빛이 있으면 밝아짐. 화면이 닫히면 원래 크기로 |
| `UiPulse` | 투명도를 천천히 오르내림 |
| `UiFloatingMotes` | 배경에 떠오르는 빛 알갱이 26개. 개수가 고정이라 매 프레임 할당 없음 |
| `CreateGlow` / `CreateSpark` / `CreateDivider` / `AddShadow` | 빛 번짐 · 반짝임 · 구분선 · 그림자 |

| 화면 | 적용 |
| --- | --- |
| **모든 버튼** | 마우스 오버 시 살짝 커짐 (`UiFactory.CreateButton`에서 한 번에) |
| **모든 패널** | 아래 그림자 (`UiFactory.CreatePanel`에서 한 번에) |
| **HUD** | 생존 정보 뒤 반투명 받침 + 보라 윗줄, 레벨 글자 뒤 금빛, **집중력 가속 중 게이지 끝 하늘색 맥동** (0이 되면 꺼짐) |
| **카드 선택** | 마우스 오버 시 카드 뒤로 **계열 색 빛**, 계열 띠 양쪽 반짝임 |
| **결과 화면** | 랭크 도장 뒤 랭크 색 빛이 조금 크게 번짐 |
| **허브 · 타이틀** | 배경에 보라 빛 알갱이가 천천히 떠오름 |

집중력 게이지 빛은 19일차 규칙을 눈으로 보여주려고 넣었다.
"빛이 나는 동안 빠르다, 꺼지면 기본 속도"가 글자를 읽지 않아도 보인다.

## 검증

```
컴파일   경고 0개 / 오류 0개
테스트   315개 통과 (Unity 전용 10개는 Unity Test Runner에서 확인)
```

추가된 테스트 (`DebugToolsTests.cs`, 26개)

- `DebugSpeedTests` — 속도 곱하기, **카드 화면은 어떤 속도에서도 0**, 멈칫에도 곱함, 범위·NaN
- `BalanceTuningTests` — 목록의 수치가 실제 필드를 가리킴, 읽기·쓰기가 같은 필드, 기본값이 슬라이더 범위 안, 정수 반올림,
  **편집해도 자산 원본 불변**, 자산 없을 때 코드 기본값 불변, 같은 값은 편집 시작 안 함, 전부/묶음 되돌리기, 저장 후 기준 교체, 재생 진입 초기화,
  **`Clone`이 모든 필드를 복사** (새 수치를 Clone에 빠뜨리면 슬라이더를 움직이는 순간 그 값이 기본값으로 튄다), 옮긴 집중력 값의 기본값 유지
- `RunStatsTests` — 층별 누적, 멈춘·잘못된 시간 무시, 모르는 층, 0초 판 비율, 층 막대 비율, 레벨 중복·다중 기록, 횟수, 시간 표기
- `DebugCheatsTests` — 켤 때만 치트 표시, 새 판에 전부 꺼짐

`BalanceAssetConsistencyTests`에 새 자산 항목 3개를 추가했다.
`CHECKLIST.md`에 **6-2. 디버그 패널 · UI 꾸미기** 구간(66~84단계)을 추가했다.
