# Project θ 개발 일지 — 12일차

## 개발 목표

11일차까지 평가 시스템을 만들었지만, 정작 플레이어가 쓸 수 있는 수단이 거의 없었다.

12일차는 **플레이어의 대응 수단**을 추가했다.

```text
A. 집중력 자원 (선행 작업)
B. 최면 파동
C. 체인 최면
D. 소비 아이템 2슬롯
E. 반격형 특성 (10일차 보류분)
```

## 문제 인식

플레이어 입장에서 할 수 있는 것과 당하는 것을 나열해 보면 불균형이 명확했다.

```text
할 수 있는 것
이동 / 대시 / 한 명 쳐다보기 / 몸으로 밀치기

당하는 것
빼앗김 / 폭주 돌진 / 각성 오라 / 시선 끊김 / 도주
```

구체적으로 다음 상황에서 플레이어가 할 수 있는 일이 없었다.

| 상황 | 기존 대응 |
| --- | --- |
| 동행 5명의 충동이 동시에 차오름 | 회수 지점까지 뛰는 것 외에 없음 |
| 금태양이 내 NPC를 쟁탈 중 | 몸으로 밀치거나, 뺏긴 뒤 다시 최면 |
| 각성 NPC 옆을 지나야 함 | 유지도가 깎이는 것을 지켜봄 |
| NPC 3명이 뭉쳐 있음 | 한 명씩 순차 공략 |

기획서 1.1절은 핵심 재미 기둥에 "과부하"를 넣어두었다. 많이 모을수록 위험해지는 구조다.

그런데 **위험을 관리할 도구가 없으면 그것은 재미가 아니라 그냥 벌**이다.

# A. 집중력 자원

기획서 13.1절. 파동·체인의 비용이 성립하려면 자원이 먼저 있어야 하므로 선행 작업으로 처리했다.

| 항목 | 값 |
| --- | ---: |
| 최대 집중력 | 100 |
| 최면 유지 소모 | 6 / sec |
| 대시 소모 | 12 / 회 |
| 회복 | 14 / sec |
| 회복 시작 지연 | 0.8초 |
| 고갈 후 재시전 임계 | 30 |

집중력이 0이 되면 최면이 강제로 끊기고, **30 이상 회복될 때까지 재시전이 막힌다.**

이것이 "무한정 쳐다보기"를 막는 유일한 제동 장치다. 지금까지는 최면 입력을 계속 누르고만 있으면 아무 대가 없이 모든 NPC를 순회할 수 있었다.

대시도 집중력을 먹으므로, 회피를 남발하면 최면을 못 건다. 기동과 공략 사이의 자원 배분이 생긴다.

계산은 `FocusLogic`으로 분리해 소모·회복·지연·임계 판정을 모두 테스트로 고정했다.

# B. 최면 파동

기획서 4.2절·7.3절. 플레이어의 핵심 대응 수단이다.

```text
우클릭 0.4초 유지 → 플레이어 중심 반경 3.5 파동
```

| 효과 | 대상 | 수치 |
| --- | --- | --- |
| 충동 안정 | 내 동행 NPC | 충동 -35 |
| 경쟁자 견제 | 금태양 · 인기남 | 1.2초 정지 + 진행 중 선점·쟁탈 초기화 |
| 각성 오라 차단 | 각성 NPC | 2.5초 무력화 |
| 비용 | — | 집중력 30, 재사용 대기 4초 |

이 하나로 앞서 나열한 **"할 수 있는 게 없는" 상황 세 개가 전부 해결**된다.

## 우클릭 충돌 처리

우클릭은 이미 힘겨루기와 포획 탈출 미니게임이 쓰고 있다.

따라서 다음 상태에서는 파동 충전이 아예 시작되지 않는다.

```text
포획 진행 중
힘겨루기 진행 중
플레이어 기절 중
스테이지 종료 후
```

충전식(0.4초)으로 만든 것도 같은 이유다. 즉발이면 미니게임 입력과 구분이 어렵다.

## 경쟁자 정지 처리

파동의 경쟁자 견제는 힘겨루기 승리 시의 기절 처리(`ApplyDuelStun`)를 그대로 재사용한다.

이 경로는 이미 타겟 해제·선점 진행도 초기화·Idle 복귀를 모두 처리하므로, 파동 전용 경로를 새로 만들 필요가 없었다. 9일차 리팩터링으로 경쟁자 제어가 공통 베이스에 모여 있던 덕분이다.

# C. 체인 최면

기획서 A.4절 "중후반 스킬로 2~3명을 잇는 체인 최면을 해금한다".

```text
대상 최면 완료
↓
반경 2.2 안에 다른 중립 NPC가 있으면 자동 연결
↓
최대 3명까지
```

| 단계 | 최면 속도 | 추가 집중력 |
| ---: | ---: | ---: |
| 1번째 | ×1.0 | 0 |
| 2번째 | ×0.7 | 15 |
| 3번째 | ×0.5 | 25 |

## 의도한 대가

3명을 모두 잇는 데 드는 추가 집중력은 **15 + 25 = 40**이다.

파동 비용이 30이므로, **체인을 끝까지 이으면 그 직후 파동을 쓸 수 없다.**

이것이 이 시스템의 핵심이다. 뭉쳐 있는 NPC를 한 번에 쓸어담을지, 집중력을 남겨 폭주에 대비할지를 매번 선택하게 만든다. 테스트로 이 관계(체인 총비용 > 파동 비용)를 고정해 두었다.

집중력이 모자라면 체인은 조용히 끊기고 일반 최면으로 돌아간다.

체인으로 확보한 NPC는 콤보가 연속 적립되므로 11일차 점수 시스템과도 바로 연결된다.

# D. 소비 아이템 2슬롯

기획서 A.8절. `1` · `2` 키로 사용한다.

| 아이템 | 효과 | 대응 상황 |
| --- | --- | --- |
| 진정제 | 동행 전원 충동 -60 | 다수 폭주 위기 |
| 집중 회복제 | 집중력 +60 | 자원 고갈 |
| 차단 부적 | 6초간 경쟁자 쟁탈 무효 | 회수 지점까지 운반 |
| 질주약 | 8초간 이동 +40%, 대시 대기 -50% | 시간 압박 |

스테이지 시작 시 **서로 다른 두 개**를 무작위로 지급한다. 같은 아이템이 두 개 나오면 다음 후보로 밀어 선택지를 보장한다.

획득 방식(드롭·구매)은 메타 시스템 작업이므로 지금은 초기 지급만 한다.

## 차단 부적 구현

쟁탈 무효는 NPC 개별이 아니라 **플레이어 무리 전체**에 걸려야 한다.

따라서 `FollowerManager`에 차단 상태를 두고, `HypnosisTarget.ApplyOpponentPressure`가 플레이어 소유 NPC를 깎기 전에 이 상태를 확인하도록 했다.

```text
경쟁자가 지배 수치 감소 시도
↓
대상이 Player 소유인가
↓
FollowerManager.IsContestWarded 인가
↓
맞으면 감소 자체를 무시
```

# E. 반격형 특성

10일차에 "집중력 자원이 없어서" 보류했던 특성이다. 이번에 선행 조건이 생겨 함께 구현했다.

| 항목 | 값 |
| --- | ---: |
| 반격 주기 | 3.2초 |
| 집중력 피해 | 20 |
| 최면 연결 차단 | 1.0초 |

최면당하는 동안에만 발동한다. 최면을 포기하면 반격도 멈춘다.

정기 가치 보정은 ×1.25다.

## 특성 배치 조정

반격형을 각 등급의 보조 특성 풀에 편입했다.

| 등급 | 고정 특성 | 보조 특성 풀 |
| --- | --- | --- |
| 일반 | 일반형 | 일반형, 일반형, 시선 회피형, 도주형 |
| 숙련 | 시선 회피형 | 일반형, 도주형, 고저항형, **반격형** |
| 희귀 | 시선 회피형, 고저항형 | 일반형, 도주형, **반격형** |
| 특수 | 고저항형, **반격형** | 일반형, 시선 회피형, 도주형 |
| 각성 | 각성 지원형, 고저항형 | 일반형 |

특수 등급은 고정 특성을 도주형에서 반격형으로 바꿨다. 선행 조건을 만족해야 공략할 수 있는 대상이 도망만 다니는 것보다, 정면으로 저항하는 쪽이 "특수"라는 이름에 맞다고 판단했다. 도주형은 보조 풀에 남겨 여전히 나올 수 있게 했다.

일반 등급 풀은 건드리지 않았다. 초반 NPC가 반격하면 학습 곡선이 너무 가팔라진다.

- 충전 완료 경계
- 충전율 Clamp
- 반경 경계값
- 시전 조건 5가지 (스테이지 종료 / 미니게임 중 / 재사용 대기 / 집중력 부족 / 정상)

`ChainHypnosisLogicTests`

- 단계별 속도 감쇠
- 단계별 추가 비용
- 최대 3명 제한
- 단계 진행 Clamp
- 연결 반경 경계
- **체인 총비용(40)이 파동 비용(30)보다 큰지** — 자원 배분 선택이 성립하는지 확인

`ConsumableSlotLogicTests`

- 슬롯이 2개뿐인지
- 빈 슬롯 사용 불가
- 시작 아이템이 풀 전체를 커버하는지
- **두 번째 슬롯이 항상 첫 번째와 다른지** (모든 조합 전수)
- 모든 아이템에 프로필이 있는지
- 지속형과 즉시형의 지속 시간 구분

`NpcTraitEffectTests` (수정)

- 특성 개수를 하드코딩 대신 열거형 길이 기준으로 변경. 특성이 추가돼도 테이블 갱신 누락을 잡아낸다.

## 12일차 결과

12일차를 기준으로 플레이어가 처음으로 **상황에 대응할 수 있게** 되었다.

이전까지는 위험이 닥치면 도망치거나 잃는 것 외에 선택지가 없었다. 이제는 파동으로 끊고, 아이템으로 버티고, 체인으로 몰아치는 선택이 생겼다.

동시에 모든 수단이 집중력 하나를 공유하므로, 무엇에 쓸지가 매 순간의 판단이 되었다. 특히 체인 최면의 총비용을 파동 비용보다 크게 잡은 것은 "욕심낼지 대비할지"를 강제로 고르게 만들기 위한 설계다.

## 남은 밸런스 작업

집중력·파동·체인의 수치는 전부 계산상의 추정값이다.

11일차에 만든 랭크 시스템을 이용해 다음을 비교하고 조정해야 한다.

```text
파동을 쓰지 않은 런
파동 위주 런
체인 최면 위주 런
아이템을 모두 소진한 런
```

어느 하나가 압도적이면 그 수단의 집중력 비용이나 재사용 대기를 올린다. 이 비교가 가능해진 것이 11일차를 먼저 진행한 이유다.
