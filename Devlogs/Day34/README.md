## A. 실패 보상 절반 (`Save/ContractEssenceLogic`)

| 결과 | 계약 정기 |
| --- | --- |
| 클리어 | 회수 × 0.5 + 랭크 보너스 + 초과 × 0.3 (그대로) |
| 실패 | **min(회수, 목표) × 0.5 × 0.5** |
| 포기 | 0 (그대로) |

- 예: 400 / 300에서 탈출하면 230, 같은 상태에서 쓰러지면 75.
- 결과 화면 계약 정기 줄에 빨간 글자 **"실패 · 보상 50% (−잃은 양)"**. 잃은 양은 숙련도(★)까지 반영해 계산한다.

## C. 목표 뒤 추격 (`Disruptors/PopulationLogic`, `DisruptorSpawner`)

```
목표 달성 ─ 추격 시작 ─ 허용 인원 +1 ─ 10초 ─ +1 ─ … ─ 층당 6명
```

- 스테이지가 탈출 가능 상태로 바뀌면 `StageMoments.ChaseStarted`를 보낸다. 연출 담당이 붉은 글자 "추격 시작! 적이 늘어납니다" · 흔들림 · 효과음을 띄운다.
- 배치표가 이미 다 나와 있으면 늘어난 자리를 채울 적이 없으므로, 추격이 시작될 때 **배치표를 한 번 더 대기열에 넣는다.**
- 증원도 추격 중에는 추격 최대 인원까지 허용한다. 어떤 값이어도 층당 8명(`HardMaxPerFloor`)은 넘지 않는다.
- 밸런스 값 `ChaseMaxPerFloor = 6` · `ChaseRampSeconds = 10`을 추가하고 F1 튜닝 위험 묶음에 넣었다.

## D. 위기 화면 효과 (`Presentation/DangerLogic`)

19일차부터 폭주 중에만 화면 가장자리가 붉게 맥동했다. 이 계산을 넓혔다.

| 위기 | 기준 | 세기 |
| --- | --- | --- |
| 체력 | 30% 이하 | 0.35 → 0.8 |
| 동행자 빼앗기기 직전 | 헌팅남 쟁탈 게이지 50% 이상 | 0.3 → 0.8 |
| 회수 지점 잠김 | 잠긴 동안 | 0.35 |
| 남은 시간 | 15초 이하 | 0.3 → 0.7 |
| 폭주 | 준비 · 폭주 · 포획 | 0.6 · 1 · 0.8 (기존) |

- 여러 위기가 겹치면 **가장 급한 것 하나**만 따른다(더하면 화면이 너무 붉어진다).
- `ContesterRole`이 살아 있는 쟁탈자 목록을 들고 있어 가장 높은 게이지를 알려 준다.
- 설정 창 일반 탭에 **위기 화면 효과 켜짐/꺼짐** 줄을 추가했다(`SaveData.DangerEffectDisabled`). 끄면 폭주 효과까지 모두 꺼진다.

## F. 저장 · 불러오기

```
메인 메뉴
 ├ 이어하기 ─ 저장 칸 창(불러오기) ─ 고른 칸 불러오기 ─ 허브
 ├ 처음부터 ─ 저장 칸 창(새로 시작) ─ 빈 칸: 바로 / 기록 있는 칸: 한 번 더 눌러 덮어쓰기 ─ 허브
 └ 설정 · 업적 · 종료
```

| 파일 | 내용 |
| --- | --- |
| `Save/SaveSlotLogic` | 칸 번호 · 파일 이름 · 요약 문구 · 새 게임 데이터 · 설정 옮기기 · 가장 최근 칸 · 옛 세이브 옮기기 조건 (순수 로직) |
| `Save/SaveSystem` | 칸 읽기 · 쓰기, 칸 요약 3개, 공용 설정 읽기 · 쓰기, 옛 세이브 옮기기. 임시 파일에 먼저 쓰고 바꿔 끼움 |
| `Save/SaveData` | `DangerEffectDisabled` · `SavedAt` · `SavedTicks` 추가 |
| `Core/GameSession` | `ActiveSlot` · `LoadSlot` · `NewGame` · `SaveNow`. `WriteSave`는 설정을 늘 저장하고, 칸을 골랐으면 칸도 저장 |
| `UI/SaveSlotPanel` | 칸 3개 창. 저장 시각 · 플레이 시간 · 계약 정기 · 클리어 장소 · 업적 수 · "최근" 표시 |
| `UI/MainMenuScreen` | `시  작` → `이어하기` · `처음부터`. 저장된 칸이 없으면 이어하기를 막음. 기록 칸에 최근 칸 표시 |
| `UI/HubScreen` | 아래 줄 `저  장` 버튼과 "N번 칸에 저장했습니다 · 시각"(4초) |

| 파일 이름 | 내용 |
| --- | --- |
| `projecttheta_slot1~3.json` | 진행 · 업적 · 통계 (칸마다) |
| `projecttheta_settings.json` | 음량 · 화면 · 커서 · 흔들림 · 위기 효과 · 키 (공용) |
| `projecttheta_save.json` | 33일차까지의 세이브. 처음 한 번 1번 칸으로 옮기고 **지우지 않음** |

- 칸을 고르기 전에는 가장 최근 칸을 미리 읽어 두고, 메인 메뉴 기록 칸과 업적 창에 보여 준다.
- 에디터에서 허브 · 지도 · 스테이지 씬을 바로 재생하면 칸을 고를 수 없으므로, 가장 최근 칸(없으면 1번 칸)에 이어서 저장한다.
- 칸을 바꾸면 진행 중이던 도전 · 넘겨받은 결과 · 업적 알림을 비워 다른 칸과 섞이지 않게 했다.
- 장소를 플레이하는 도중에는 저장하지 않는다(도중에 끄면 그 장소 기록은 남지 않음, 예전과 같음).
