# 부록 C. 방해 세력 설계

본 부록은 부록 B의 도시 장소 8곳에 배치할 방해 세력을 정의한다.
9장(방해 및 저항 세력), A.7(라이벌 · 쟁탈), B.4(역할표)를 구체적인 캐릭터 · 행동 · 수치로 옮긴 1차 설계안이며, 수치는 모두 **초기안**이다.

방해 세력은 전원 성인이며, 직접 체력 전투는 사용하지 않는다(A.4). 플레이어는 회피 · 위치 선정 · 최면 파동 · 환경 이용으로 대응한다.

---

## C.1 설계 원칙

1. **역할이 먼저, 외형은 나중.** 모든 방해 세력은 7개 역할(감시 · 구출 · 쟁탈 · 길막 · 힘 대결 · 도둑 · 관문) 중 하나의 공통 동작 위에 만든다. 장소별 캐릭터는 역할의 외형 · 수치 · 특수 능력만 다르다.
2. **보이면 피할 수 있어야 한다.** 모든 위협은 발동 전에 예고(아이콘 · 소리 · 모션)가 있다. 예고 없는 페널티는 두지 않는다.
3. **대처법이 두 가지 이상.** 모든 방해 세력은 "피하기"와 "무력화하기" 중 최소 두 가지 방법으로 대응할 수 있다.
4. **특수 능력은 일부에게만.** 일반 방해 세력은 역할 동작만 한다. 장소마다 1~2명의 **특수 개체**만 고유 능력을 가진다. 특수 개체는 이름표와 테두리 색으로 구분한다.
5. **장소의 규칙을 강화한다.** 방해 세력의 능력은 그 장소의 환경 규칙(B.3)과 맞물리게 설계한다.

---

## C.2 공통 시스템

### C.2.1 경계도

감시 역할 방해 세력이 공유하는 구역 단위 게이지다. 9.2(감시자)의 경계 게이지를 구역 전체로 확장한다.

| 단계 | 경계도 | 효과 |
| --- | ---: | --- |
| 평온 | 0~29 | 효과 없음 |
| 주의 | 30~59 | 감시자 순찰 속도 +20%, 주변 일반 NPC 최면 저항 +10% |
| 경계 | 60~89 | 감시자가 마지막 발견 지점으로 이동, 특수 개체 능력 재사용 대기 -30% |
| 비상 | 90~100 | 증원 1명 등장(구역당 최대 2회), 10초 동안 회수 지점 1곳 잠김 |

- 경계도는 발각 행동(시야 안 최면, 달리기 소음, 조명 노출)으로 오르고, 발각이 없으면 초당 **4**씩 내려간다.
- 최면 파동을 감시자에게 맞히면 경계도 **-15**, 해당 감시자 **3초 멍함**.
- HUD 상단에 구역 경계도 막대를 표시하고, 단계가 오를 때 짧은 경고음을 낸다.

### C.2.2 발각 판정

| 요소 | 초기안 |
| --- | --- |
| 기본 시야 | 부채꼴 60°, 거리 6m |
| 시야 안에서 최면 유지 | 초당 경계도 +12 |
| 시야 안에서 달리기 · 대시 | 1회 +8 |
| 동행자 수 보정 | 동행자 1명당 발각 속도 +5% (많이 끌고 다닐수록 눈에 띔) |
| 발각 예고 | 머리 위 `?` (0.8초) → `!` 전환 시 판정 |

### C.2.3 역할별 공통 동작

| 역할 | 공통 동작 | 공통 대처 |
| --- | --- | --- |
| **감시** | 순찰 경로 이동, 시야 판정, 경계도 상승, 발견 시 추적 | 시야 밖 우회, 엄폐, 파동으로 멍함 |
| **구출** | 최면 중 · 동행 중 NPC에게 접근해 유지도 감소 또는 게이지 초기화 | 동행자와 거리 벌리기, 접근 경로 차단, 파동 |
| **쟁탈** | 동행자에게 접근해 영향력 탈취 (8장 쟁탈 게이지) | 재최면, 힘겨루기, 파동으로 연결 끊기 |
| **길막** | 통로 · 시야를 몸으로 막음, 최면 불가 | 우회, 밀치기(대시 접촉 시 1m 밀림), 시간 경과 |
| **힘 대결** | 접촉 시 힘겨루기(10일차 구현) 강제 시작 | 접촉 회피, 힘겨루기 승리 |
| **도둑** | 미회수 정기(동행자 정기 가치)를 훔쳐 도주 | 추격 후 접촉으로 회수, 빨리 회수 지점 이용 |
| **관문** | 통로 통과 조건 요구 | 조건 충족, 우회로, 특정 NPC 최면 |

### C.2.4 특수 개체 공통 규칙

- 구역당 최대 **2명**. 이름표(예: `라이프가드 반장`)와 금색 테두리로 표시한다.
- 능력 발동 **1.0~1.5초 전 예고**(머리 위 능력 아이콘 + 전용 효과음)를 반드시 준다.
- 능력은 재사용 대기시간을 가지며, 경계 단계에서 대기시간이 짧아진다.
- 특수 개체를 최면 파동으로 멍하게 만들면 **능력 대기시간이 초기화되지 않고 멈춘다**(멍함 동안 발동 불가).
- 특수 개체를 무력화한 채 구역을 끝내면 점수 보너스 **+300**.

- 정신력 0: A.10 규칙 적용 (5초 조작 불능 · 세력 일부 손실 · 절반 회복, 짧은 시간 연속 붕괴 시 패배).

## C.9 기술 구현 방향

현재 코드 구조를 기준으로 한 확장 방향이다.

| 구성 요소 | 방향 |
| --- | --- |
| `DisruptorBase` | 방해 세력 공통 기반. 순찰 경로, 멍함, 층(구역) 판정, 활성 목록 등록. 현재 `OpponentControllerBase`의 활성 목록 · 층 판정 구조를 재사용 |
| 역할 컴포넌트 | `WatcherRole`(감시) · `RescuerRole`(구출) · `ContesterRole`(쟁탈, 기존 쟁탈 로직 이관) · `BlockerRole`(길막) · `DuelistRole`(힘 대결, 기존 힘겨루기 연결) · `ThiefRole`(도둑) · `GateRole`(관문) |
| `SpecialAbility` | 예고 시간 · 재사용 · 발동 조건 · 효과를 가진 데이터 + 실행 컴포넌트. 개체에 0~1개 부착 |
| `ZoneAlert` | 구역 경계도 상태. 순수 계산(`ZoneAlertLogic`)과 컴포넌트를 분리해 EditMode 테스트 |
| `DisruptorDatabase` | 역할 · 수치 · 능력 · 난이도 배율을 담는 자산. 기존 `NpcDatabase` · `StageBalanceDatabase`와 같은 주입 구조 |
| 연출 | 예고와 발동은 `StageMoments` 알림으로 보내고 `StageVfxDirector`가 연출 · 효과음을 붙인다 (19일차 구조) |
| 디버그 | 디버그 패널 치트 탭에 "특수 능력 즉시 발동", 상태 탭에 "구역 경계도" 추가 |

**제작 순서 초기안**: `ZoneAlert` + `WatcherRole` → `SpecialAbility` 틀 → 해변가(라이프가드 · 반장 · 헌팅남) → 야시장(호객꾼 · 촬영팀 · 소매치기) → 이후 장소 순.

## C.10 결정 로그 추가 (30.2에 반영)

- 방해 세력은 역할 7종(감시 · 구출 · 쟁탈 · 길막 · 힘 대결 · 도둑 · 관문) 위에 장소별 외형을 입히는 구조로 한다.
- 장소마다 특수 개체 1~2명만 고유 능력을 가지며, 모든 특수 능력은 1.0초 이상의 예고를 가진다.
- 구역 단위 경계도(평온 · 주의 · 경계 · 비상)를 도입해 9.2 감시자의 경계 게이지를 확장한다.
- 소매치기(도둑 역할)는 동행자가 아닌 **미회수 정기**를 빼앗아, "많이 모아 늦게 회수"하는 욕심에 새로운 위험을 준다.
- 라이벌 서큐버스 보스전은 루프탑 클럽에서 음악 박자 · 조명 점멸 규칙과 결합한다.
