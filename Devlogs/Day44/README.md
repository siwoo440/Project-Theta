# 44일차 — 르미아 메인 인터루드와 루프탑 결전 연결

---
## 개발 방향

- 최신 스토리 탭의 지역 자유 진행을 유지하면서 완료 지역 수에 따라 르미아 메인 인터루드가 열리도록 구성했다.
- 현재 루프탑이 일반 지역과 보스전으로 분리되지 않은 구조이므로, 7개 일반 지역 조사와 결전 전야를 완료한 뒤 루프탑 보스전에 진입하도록 범위를 정했다.
- 루프탑의 에스텔 개인 지역 에피소드와 보스전 분리는 후속 지역 스테이지 구조 작업으로 남겼다.

---
## 구현

- 일반 지역 완료 수를 이야기 조건으로 사용할 수 있는 `RegionalStoriesCompleted` 조건을 추가했다.
- 2개 지역 완료 후 인터루드 A, 4개 후 인터루드 B, 6개 후 인터루드 C가 허브 복귀 때 순서대로 재생되도록 연결했다.
- 르미아의 동행자 쟁탈과 재탈환 장면을 실제 `FollowerStolen`·`FollowerReclaimed` 사건에 연결했다.
- 7개 일반 지역과 인터루드 C 완료 후 `두 개의 진실`과 `결전 전야`가 이어지도록 구성했다.
- 같은 허브 복귀에서 앞 장면 완료로 새로 열린 후속 장면을 즉시 재조회하도록 수정했다.
- 결전 전야 완료 전에는 지도에서 루프탑 선택과 출격을 차단하고 해금 조건을 표시하도록 수정했다.
- 루프탑 진입 시 보스 개막 장면, 보스 승리 후 르미아의 마지막 대화가 재생되도록 추가했다.
- Google 기획서 `필요 리소스` 탭에 UI 묶음 8개와 개별 제작 리소스 44개를 추가했다.

- 전체 이야기 표의 중복 ID·누락 선행 장면·순환 조건 0건 확인

---
## 확인 제한

- Unity 편집기가 실행 중이어서 별도 배치 모드 전체 Unity Test Runner는 실행하지 않았다.
- 지도에서 잠긴 루프탑 노드의 실제 색상·문구 배치와 결전 장면의 입력 흐름은 Unity 화면 확인이 필요하다.
- 루프탑 에스텔 일반 지역 에피소드와 최종 보스전은 현재 같은 장소 실행 경로를 사용하므로 아직 분리되지 않았다.
