# 23일차 - 해변가 · 야시장 장소 구현

## 이번 일차의 목표

22일차에 만든 방해 세력 공통 틀(설정표 + 역할 + 특수 능력 + 구역 경계도)을 써서,
색 · NPC 수만 다르던 임시 장소 두 곳을 **실제 장소**로 채웠다.

1. **해변가 (낮)** — "넓은데 숨을 곳이 없다". 파라솔 그늘 · 밀물 · 동시 운반
2. **야시장 (밤)** — "밝은 곳은 기회, 어두운 곳은 위험". 어둠과 등불 · 좁은 골목 · 소매치기
3. 감시 말고 처음 동작하는 역할 **쟁탈 · 길막 · 도둑**

## 기획 결정

### 대처 수단이 늘 하나 이상 있다

새 위협마다 플레이어가 할 수 있는 대응을 먼저 정했다.

| 위협 | 대처 |
| --- | --- |
| 라이프가드 시야 | 파라솔 그늘 안에서 최면 |
| 호루라기 경보 | 망루 뒤편에서 활동, 파동, 반경 밖 NPC 공략 |
| 헌팅남 | 동행자 곁을 지키기(무리를 촘촘하게), 파동, 차단 부적 |
| 밀물 | 예고 3초 동안 물가 줄에서 벗어나기 |
| 호객꾼 | 노점 반대편 줄로 걷기, 돌아가 1초 곁에 서서 되찾기 |
| 취객 | 거리 두기, 대시로 밀치기 |
| 라이브 방송 | 조명 경로 밖에서 활동, 파동으로 조명 끄기 |
| 슬쩍하기 | 예고 1초 동안 대시로 거리 벌리기, 도주하면 쫓아가 닿기 |

### 욕심에 대한 새로운 벌

소매치기는 동행자가 아니라 **아직 회수하지 않은 정기**를 노린다.
"많이 모아 늦게 회수"하는 플레이에 동행자를 잃는 것과 다른 종류의 손해를 준다.

## A. 해변가

| 적 | 역할 | 특징 |
| --- | --- | --- |
| 라이프가드 ×2 | 감시 | 시야 35° · 9m, 순찰 2.6m/s |
| 헌팅남 ×1조(2명) | 쟁탈 | 무리 맨 뒤 · 뒤에서 두 번째 동행자를 각각 노림. "♥ N%" 게이지 초당 15, 가득 차면 데려감 |
| 라이프가드 반장 ◆ | 감시 · 특수 | 망루 앞 고정, 시야 60° · 12m, **호루라기 경보** |

**호루라기 경보** — 반장이 발각하면 1초 예고 뒤 반경 10m 중립 NPC가 8초 "경계!"(최면 속도 절반), 경계도 +25, 재사용 15초

| 규칙 | 내용 |
| --- | --- |
| 밀물 · 썰물 | 30초 주기. 썰물 19초 → 예고 3초 → 밀물 8초. 밀물 동안 화면 아래쪽 줄이 잠기고 그 줄의 플레이어 · 동행자는 모래 쪽으로 밀려남 |
| 파라솔 그늘 | 4곳. 그늘 안의 플레이어는 감시 시야 판정에서 빠짐 |
| 동시 운반 | 한 번에 3명 이상 회수하면 정기 ×1.2, 1~2명씩이면 ×0.5 |

## B. 야시장

| 적 | 역할 | 특징 |
| --- | --- | --- |
| 호객꾼 ×노점 4곳 | 쟁탈(붙잡기) | 노점 3m 안 동행자를 세움. 6초 안에 곁에 1초 서면 되찾기, 못 하면 이탈 |
| 취객 ×2 | 길막 | 비틀거리며 이동, 부딪히면 동행자 충동 +15 (2초 간격), 대시에 1m 밀려나고 1초 멈춤 |
| 촬영팀 ◆ | 감시 · 특수 | 앞쪽에 조명(반경 3m), **라이브 방송** |
| 소매치기 ◆ | 도둑 · 특수 | 발동 전까지 이름표 숨김, **슬쩍하기** |

**라이브 방송** — 조명 안에서 최면하면 1초 예고 뒤 "● LIVE", 경계도 +30, 8초 추적, 재사용 18초. 조명 안은 등불처럼 사거리가 온전하다.

**슬쩍하기** — 3m 안에 들어오면 등 뒤로 다가가 1초 예고("✋ 등 뒤!"). 2m 안에 남아 있으면 미회수 정기의 30%를 훔친다.

- 데리고 있던 동행자 모두에게 "털림 -30%" 표식 (회수 정기 70%)
- 20초 안에 닿으면 표식 모두 해제 + 보너스 +50, 못 잡으면 퇴장
- 구역당 한 번

| 규칙 | 내용 |
| --- | --- |
| 어둠과 등불 | 노점 등불(반경 2.2) 안에서만 최면 사거리 100%, 밖은 70%. 등불 사이에 어두운 틈이 있음 |
| 좁은 골목 | 동행자가 한 줄로 따라옴 |
| 증원 없음 | 순찰형 감시자가 없어 비상 때 회수 지점 잠금만 걸림 |

## C. 구조 변경

- 설정표에 `IgnoresShade`(그늘 무시) · `HiddenUntilFired`(이름표 숨김), 배치에 `Variant`(2인조 순번) 추가
- 장소별 증원 종류 (`GetReinforcementKind`)
- 특수 능력에 `HasFired`, 충동에 `AddImpulse`, 동행 관리에 `SingleFile`
- 소품(노점 · 망루 · 파라솔 · 물 · 등불)은 코드로 그리는 임시 그림 (`LocationProps`)

## D. HUD · 연출 · 디버그 · 밸런스

- HUD 경계도 막대 아래 한 줄 — "다음 밀물까지 N초 · 동시 운반 …", "파도가 온다!", "소매치기 도주 중 N초 · 털린 정기 N"
- 연출 — 파도 예고, 도난(흔들림 · 도장음), 되찾기(반짝임 · 회수음)
- 머리 위 — `♥ N%`, `어서 오세요~`, `● LIVE`, `도주 N`, NPC "경계!", 동행자 "호객 중 N" · "털림 -30%"
- 치트 — `밀물 즉시 (해변가)`, `소매치기 발동 (야시장)`
- 수치 슬라이더 — 어둠 속 최면 사거리(0.7), 헌팅 쟁탈 속도 배율(1)
