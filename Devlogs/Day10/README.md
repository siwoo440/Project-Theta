# Project θ 개발 일지 — 10일차

## 개발 목표

9일차까지 구축한 플레이어·금태양·인기남의 NPC 소유권 경쟁에 플레이어가 직접 개입할 수 있는 **경쟁자 힘겨루기 시스템**을 추가했다.

동시에 인기남의 Neutral NPC 선점 방식을 즉시 확보에서 **3단계 선점 방식**으로 변경하여, 플레이어가 진행 타이밍을 보고 개입할 수 있도록 조정했다.

---

## 1. 경쟁자 힘겨루기 시스템

금태양 또는 인기남이 NPC 확보 행동을 진행하는 상황에서 플레이어가 해당 경쟁자와 접촉하면 힘겨루기를 시작할 수 있다.

힘겨루기 중에는 중앙 패널이 표시되고 플레이어의 이동, 대시, 최면 입력을 잠근다.

입력 방식은 기존 포획 탈출 미니게임과 동일한 감각을 유지하기 위해 좌·우 마우스 클릭을 번갈아 사용하는 구조로 구현했다.

```text
좌클릭 → 우클릭 → 좌클릭 → 우클릭 ...
```

올바른 교대 입력만 플레이어 쪽으로 힘겨루기 게이지를 이동시키며, 같은 버튼을 연속해서 입력해도 진행도가 증가하지 않는다.

---

## 2. 힘겨루기 승패 기준

힘겨루기 게이지는 0~100 범위를 사용한다.

초기값은 50이며, 최종 승패 구간은 다음과 같다.

```text
0% ───── 10% │──────── 힘겨루기 영역 ────────│ 90% ───── 100%
             플레이어 패배                    플레이어 승리
```

### 플레이어 승리

게이지가 **90% 이상**이 되는 즉시 플레이어 승리로 처리한다.

### 플레이어 패배

게이지가 **10% 이하**가 되는 즉시 플레이어 패배로 처리한다.

HUD에는 10%와 90% 위치에 세로 기준선을 표시하여 승패 경계를 바로 확인할 수 있도록 했다.

---

## 3. 임계값을 넘었는데 종료되지 않던 문제 수정

초기 구현에서는 힘겨루기가 0% 또는 100%까지 도달해야 종료되었다.

또한 플레이어 입력으로 승리 구간에 도달한 프레임에도 상대 압력이 먼저 적용된 뒤 승패를 판정하여, 게이지가 다시 90% 아래로 내려가면서 승리가 누락되는 상황이 발생할 수 있었다.

이를 다음 순서로 수정했다.

```text
플레이어 교대 입력 처리
↓
즉시 10% / 90% 승패 판정
↓
승패 미결정일 경우에만 상대 압력 적용
↓
다시 승패 판정
```

따라서 이제 게이지가 임계선을 넘는 즉시 힘겨루기가 종료된다.

---

## 4. 힘겨루기 기본 수치

| 항목 | 값 |
| --- | ---: |
| 시작 게이지 | 50 / 100 |
| 올바른 교대 클릭 | +8 |
| 상대 자동 압력 | -10 / sec |
| 플레이어 승리 | 90% 이상 |
| 플레이어 패배 | 10% 이하 |
| 플레이어 패배 피해 | 10 HP |
| 플레이어 기절 | 1.75초 |
| 상대 기절 | 2.5초 |
| 상대 패배 한계 | 3회 |
| 상대 밀려남 거리 | 1.8 |
| 플레이어 밀려남 거리 | 1.6 |

---

## 5. 플레이어 승리 처리

힘겨루기에서 플레이어가 승리하면 상대를 플레이어 반대 방향으로 밀어낸다.

```text
플레이어 승리
↓
경쟁자 밀려남
↓
패배 횟수 +1
↓
2.5초 기절
↓
Idle / Search 복귀
```

상대별 패배 횟수는 3회까지 누적된다.

```text
● ● ●
↓
● ● ○
↓
● ○ ○
↓
○ ○ ○
```

3번째 패배 시 해당 경쟁자는 필드에서 제거된다.

---

## 6. 경쟁자 퇴장과 소유 NPC 해제

금태양 또는 인기남이 힘겨루기에서 세 번 패배하면 해당 경쟁자를 필드에서 비활성화한다.

동시에 그 경쟁자가 확보한 NPC도 모두 해제한다.

```text
경쟁자 3회 패배
↓
필드 퇴장
↓
해당 경쟁자의 Follower 목록에서 NPC 제거
↓
NPC Owner = Neutral
↓
최면 수치 = 0
↓
일반 NPC 상태 복귀
```

이를 통해 플레이어는 경쟁자를 직접 제거하여 상대가 누적해서 확보한 NPC 전체를 다시 중립 상태로 돌릴 수 있다.

---

## 7. 플레이어 패배 처리

힘겨루기 게이지가 10% 이하가 되면 상대가 승리한다.

```text
플레이어 패배
↓
HP -10
↓
상대 반대 방향으로 밀려남
↓
1.75초 기절
```

플레이어 기절 중에는 이동, 대시, 최면, 새로운 힘겨루기 시작을 제한한다.

HP가 0이 되면 기존 Stage 실패 처리를 그대로 사용한다.

---

## 8. 금태양 힘겨루기 조건

금태양은 Player 소유 NPC를 실제로 쟁탈하는 상황에서 플레이어가 접촉하면 힘겨루기를 시작한다.

```text
금태양
↓
Player NPC 접근 및 Contest
↓
플레이어 접촉
↓
힘겨루기
```

---

## 9. 인기남 힘겨루기 조건 수정

초기 10일차 구현에서는 인기남의 힘겨루기 시작 조건이 너무 좁게 설정되어 있었다.

기존 조건은 다음과 같았다.

```text
State == Contest
TargetMode == Contest
Target Owner == Player
```

이 때문에 인기남이 가장 자주 수행하는 Neutral NPC 선점 중에는 플레이어가 접촉해도 힘겨루기가 시작되지 않았다.

이를 수정하여 인기남이 **NPC 확보 행동을 실제로 수행 중이라면 플레이어가 몸으로 개입할 수 있도록** 조건을 확장했다.

현재 힘겨루기 가능 상태는 다음과 같다.

```text
Neutral NPC를 향해 Approach
Neutral NPC Claiming

Player NPC를 향해 Contest Approach
Player NPC Contest

금태양 NPC를 향해 Contest Approach
금태양 NPC Contest
```

따라서 인기남의 선점을 초반부터 직접 방해할 수 있다.

---

## 10. 인기남 Neutral NPC 단계형 선점

9일차까지 인기남은 Neutral NPC에 접근하면 즉시 자신의 소유로 전환했다.

10일차부터는 다음과 같이 세 단계에 걸쳐 선점한다.

```text
접근
↓
띡 / 1⁄3
↓
띡 / 2⁄3
↓
띡 / 3⁄3
↓
인기남 소유
```

각 단계의 기본 간격은 **0.75초**다.

따라서 전체 선점에는 약 **2.25초**가 필요하다.

플레이어는 이 진행도를 확인하고 인기남에게 직접 힘겨루기를 걸거나, 해당 NPC를 먼저 최면해 가져가는 식으로 대응할 수 있다.

---

## 11. 인기남 선점 진행도 UI

Neutral NPC에 표시되는 진행도를 플레이어 최면과 인기남 선점으로 구분했다.

```text
상단 보라색 게이지
→ 플레이어 Neutral NPC 최면 진행도

하단 청록색 게이지
→ 인기남 Neutral NPC 선점 진행도
```

인기남의 게이지는 연속 증가가 아니라 다음 세 단계로 이동한다.

```text
0
→ 1/3
→ 2/3
→ 3/3
```

인기남이 타겟을 포기하거나 힘겨루기에서 밀려나면 진행 중이던 선점 상태를 초기화한다.

---

## 12. 인기남 선점 효과음

인기남의 선점 단계가 한 단계 진행될 때마다 짧은 `띡` 효과음을 재생한다.

현재 프로토타입에서는 별도 오디오 파일을 추가하지 않고 런타임에서 짧은 AudioClip을 생성하여 사용한다.

추후 정식 효과음이 준비되면 현재 재생 지점을 그대로 활용해 교체할 수 있다.

---

## 13. 경쟁자 Stunned 상태

금태양과 인기남 모두 힘겨루기 패배 시 `Stunned` 상태로 전환된다.

기절 상태에서는 다음 행동을 중단한다.

- 이동
- 타겟 검색
- NPC 접근
- NPC 쟁탈
- Neutral NPC 선점

기절이 종료된 후에는 이전 타겟을 즉시 이어서 공격하지 않고 Idle 상태를 거쳐 다시 행동한다.

---

## 14. 인기남 선점 중 힘겨루기 흐름

최종적으로 인기남과의 직접 개입은 다음과 같이 동작한다.

```text
인기남이 Neutral NPC 발견
↓
Approach
↓
1/3 선점
↓
플레이어가 인기남에게 접촉
↓
힘겨루기 패널 표시
↓
좌클릭 ↔ 우클릭 교대
↓
플레이어 승리
↓
인기남 밀려남 + 기절
↓
해당 Neutral NPC 선점 진행도 초기화
```

---

## 15. Capture 시스템과 힘겨루기 충돌 방지

기존 폭주 NPC 포획 미니게임과 경쟁자 힘겨루기는 동시에 실행되지 않도록 처리했다.

```text
Capture 중
→ 힘겨루기 시작 불가

힘겨루기 중
→ Capture 시작 불가

플레이어 기절 중
→ Capture / 힘겨루기 시작 불가

Stage 종료
→ 진행 중인 힘겨루기 강제 종료
```

두 시스템 모두 좌·우 클릭을 사용하므로 입력 충돌을 방지하기 위한 처리다.

---

## 16. 경쟁자 전용 캐릭터 리소스 유지

금태양과 인기남은 각각 전용 캐릭터 리소스를 사용한다.

```text
금태양
Characters/Geumtaeyang

인기남
Characters/PopularGuy
```

두 캐릭터 모두 원본 색상을 유지하기 위해 `Color.white` Tint를 사용한다.

플레이어는 기존대로 `Characters/Player` 리소스를 사용한다.

## 17. 테스트 및 로직 분리

10일차 기능을 위해 힘겨루기 계산과 인기남 힘겨루기 가능 조건을 별도 로직으로 분리했다.

주요 테스트 대상은 다음과 같다.

### OpponentDuelLogicTests

- 좌우 교대 입력 판정
- 잘못된 연속 입력 무시
- 상대 자동 압력 계산
- 10% 이하 즉시 패배
- 90% 이상 즉시 승리
- 10% 초과 ~ 90% 미만에서는 힘겨루기 지속

### OpponentDuelDurabilityLogicTests

- 상대 패배 횟수 누적
- 세 번째 패배에서 퇴장 조건 충족

### PopularGuyNeutralClaimLogicTests

- 1/3 → 2/3 → 3/3 진행
- 최대 3단계 Clamp
- 3단계 도달 시 선점 완료

### PopularGuyDuelLogicTests

- Neutral NPC Approach 상태에서 힘겨루기 가능
- Neutral NPC Claiming 상태에서 힘겨루기 가능
- Player NPC Contest Approach/Contest 상태에서 힘겨루기 가능
- 금태양 NPC Contest 상황에서 힘겨루기 가능
- Idle, Stunned, 자기 소유 NPC 상태에서는 힘겨루기 불가

플레이어는 1/3 또는 2/3 진행 중인 인기남에게 직접 접촉해 힘겨루기를 걸 수 있다.

## 10일차 결과

10일차를 기준으로 Project θ의 NPC 경쟁 시스템은 단순히 플레이어와 AI가 최면 수치를 주고받는 구조에서 벗어나, 플레이어가 경쟁자의 행동을 직접 발견하고 몸으로 저지하는 **능동적인 대결 구조**로 확장되었다.

금태양은 Player 소유 NPC를 직접 빼앗는 공격적인 경쟁자이고, 인기남은 Neutral NPC를 단계적으로 선점하면서 다른 세력 NPC까지 노리는 경쟁자로 유지된다.

플레이어는 두 경쟁자의 행동 타이밍을 읽고 접근하여 힘겨루기를 걸거나, NPC를 먼저 확보하는 선택을 할 수 있게 되었다.
