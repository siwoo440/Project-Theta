# 45일차 — 리엘라 호감도와 엔딩 A/B/C 분기

---
## 개발 방향

- 리엘라 관계 이벤트와 일반 지역 첫 완료를 호감도에 연결하고 세이브에 영구 저장한다.
- 최종전 패배는 엔딩 C, 승리와 호감도 79 이하는 엔딩 A, 승리와 호감도 80 이상은 엔딩 A/B 선택으로 분기한다.
- 엔딩 종류와 누적 횟수를 기록해 기존 심야 모드 해금 규칙과 연결한다.

---
## 구현

- 리엘라 호감도 0~100 범위와 보상 ID 기반 중복 지급 방지 규칙을 추가했다.
- 관계 이벤트 H01~H06은 각각 +10, 현재 일반 지역 7곳의 첫 완료는 각각 +1로 연결했다.
- 이전 저장의 완료 장면을 읽어 누락된 호감도와 지급 기록을 중복 없이 복원하도록 구성했다.
- 첫 지역, 인터루드 A·B·C, 스토리 13 진행에 맞춘 리엘라 관계 이벤트 H02~H06을 추가했다.
- 최종전 승패·포기 여부·호감도 80 기준의 엔딩 분기 규칙을 추가했다.
- 엔딩 A/B 선택 화면과 엔딩별 제목·문장을 추가하고 연출 완료 뒤 결과를 저장하도록 변경했다.
- 고유 엔딩 A/B/C와 전체 엔딩 횟수를 저장하고 엔딩 C도 심야 모드 해금에 포함했다.

---
## 현재 범위

- 기획서의 최대 호감도 구성은 고유 개인 스테이지 40개와 관계 이벤트 6개를 합친 100이다.
- 현재 게임에는 일반 지역 첫 완료 장면이 7개뿐이므로 최종전 전 자연 획득 가능한 호감도는 67이다.
- 엔딩 B 분기와 선택 UI는 구현했지만 추가 고유 개인 스테이지가 연결되기 전에는 정상 진행으로 호감도 80에 도달할 수 없다.

---
## 검증

- 호감도 중복 지급·상한·이전 저장 복원 테스트를 추가했다.
- 관계 이벤트 해금 순서와 엔딩 79/80 경계 테스트를 추가했다.
- 엔딩별 기록·심야 모드 해금·연출 자료 테스트를 추가했다.
- `Day45Tests` 9개와 관련 회귀 테스트를 합쳐 60개 통과를 확인했다.
- 테스트 프로젝트와 전체 솔루션 빌드 경고 0개, 오류 0개를 확인했다.

---
## 확인 제한

- 엔딩 선택 버튼 배치와 A/B/C 연출의 실제 화면 흐름은 Unity 플레이 모드 확인이 필요하다.
- `JsonUtility` 기반 구버전 JSON 테스트 1개는 외부 리플렉션 실행기의 Unity 네이티브 호출 제한으로 제외했다.
- 전체 40개 고유 개인 스테이지의 제작과 호감도 연결은 후속 개발 범위다.
