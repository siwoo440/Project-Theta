# 통합 점검 1회차 (실행 파일)

전체 확인 목록(`Devlogs/Day18/CHECKLIST.md`, 371줄)은 한 번에 돌기 길다.
여기서는 **실행 파일로 게임 흐름을 한 바퀴 도는 40줄**만 고른다.
어긋난 줄은 "결과"에 ✗와 메모를 적고, 자세한 확인은 "관련 번호"의 전체 목록 줄을 본다.

- 준비: Unity 메뉴 `Project Theta/빌드/Windows 실행 파일` → `Builds/Windows/ProjectTheta.exe`
  - 성능 기록까지 보려면 `Windows 개발 빌드`로 한 번 더 만든다(`Builds/WindowsDev/`).
- 새 칸으로 시작한다. 기존 칸은 건드리지 않는다(저장 칸 3개 중 빈 칸 사용).
- 소요: 약 40~50분 (장소 3곳 + 보스 + 심야 1판)
- 치트가 필요한 줄(보스 · 엔딩)은 **개발 빌드**에서 `F1`로 진행한다.
