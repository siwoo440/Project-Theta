# 31일차 - 일시정지 · 설정 · 조작법 · 종료 구현

## 이번 일차의 목표

30일차 뒤 게임 전체를 점검하면서 부족한 부분 9가지를 뽑았고, 그중 **기본 편의 기능**을 먼저 채웠다.
그전까지는 게임을 멈추거나, 끄거나, 소리를 줄이거나, 조작법을 다시 볼 방법이 없었다.

| 기능 | 어디서 |
| --- | --- |
| 일시정지 메뉴 (계속 · 조작법 · 설정 · 포기) | 스테이지 Esc |
| 설정 창 (음량 3종 · 화면 · 해상도 · 커서 크기 · 화면 흔들림) | 메인 메뉴 · 허브 · 일시정지 |
| 조작법 창 | 메인 메뉴 · 허브 · 일시정지 |
| 게임 종료 | 메인 메뉴 |
| 도중 포기 | 일시정지 |

## 기획 결정

| 질문 | 결정 |
| --- | --- |
| 도중 포기 시 보상 | **계약 정기 0**, 최고 점수에도 넣지 않음. 통계에는 도전 1회 |
| 해상도 선택지 | **기본 3개** (1280×720 · 1600×900 · 1920×1080) |
| 커서 크기 설정 | **넣음** (작게 0.75 · 보통 1 · 크게 1.35) |

- 계획에서는 일시정지에 `포기하고 지도로` · `허브로`를 따로 두려 했지만, 통계를 남기려면 결과 화면을 거쳐야 하고
  결과 화면에 이미 두 버튼이 있어 **`포기하기` 하나**로 합쳤다.
- 해상도 · 창 모드는 에디터 Game 창에서는 바뀌지 않으므로 실행 파일에서만 적용한다.

## A. 설정 저장 · 적용

- `SaveData`: `MasterVolume` · `SfxVolume` · `MusicVolume` · `Fullscreen` · `ResolutionIndex` · `CursorSize` · `SettingsInitialized`
- `SettingsLogic`: 기본값(음량 80% · 전체화면 · 1920×1080 · 커서 보통), 범위 고정, 실제 음량(전체 × 효과음), 해상도 · 커서 표
- `SettingsApplier`: `GameAudio` 배율 · `CameraShake` · 커서 배율 · 화면 모드를 적용하고 `Changed`로 알린다. 게임을 켤 때(`GameSession.Awake`)와 설정을 바꿀 때 부른다.
- `GameAudio.SfxVolume`: 모든 효과음에 곱한다. `MusicVolume`은 배경음악을 넣을 때를 위한 자리.

### 예전 세이브 무음 문제

예전 세이브에는 음량 칸이 없어서 JSON을 읽으면 0으로 채워질 수 있다. 그대로면 업데이트 뒤 **소리가 안 나는** 문제가 생긴다.
`SettingsInitialized`가 false이면 설정을 한 번도 저장하지 않은 것으로 보고 기본값을 넣는다.
사용자가 일부러 0%로 저장한 값은 그대로 둔다(테스트로 고정).

## B. 공통 틀

- `UiOverlay`: 어두운 막(뒤 클릭 차단) · 가운데 창 · 제목 · 닫기 버튼. 설정 · 조작법 · 일시정지가 같이 쓴다.
- `UiEscapeStack`: Esc를 쓰는 창이 여럿이라, **가장 위에 열린 창만** 닫고 한 프레임에 Esc를 한 번만 쓰게 한다.
  열린 창이 없을 때만 일시정지가 열리고, 창을 닫은 같은 프레임에 일시정지가 열리지 않는다.
  통계 창(지도) · 업적 창(허브)도 이 순서를 따르게 바꿨다.

## C. 창

### 일시정지 (`PauseMenu`)

- 스테이지마다 부트스트랩이 만든다. 멈춤은 `GameplayPause.Request/Release`.
- 카드 선택 · 결과 화면 · 보스 엔딩 · 로딩 중에는 열지 않는다(`PauseMenuLogic.CanOpen`).
- 스테이지가 끝나면 스스로 닫고, 씬을 나갈 때도 멈춤을 푼다.

### 포기

- `StageState.Abandoned`를 **맨 뒤에** 추가해 기존 번호(0~3)를 유지했다.
- `StageSessionController.Abandon()` → 상태를 다시 계산하지 않는다. 결과 제목 "GAVE UP".
- 결과 화면이 계약 정기 0(`PauseMenuLogic.GetContractEssence`) · 점수 0으로 넘긴다.

### 설정 (`SettingsPanel`)

- 슬라이더를 끄는 동안 0.12초마다 "딱" 소리로 크기를 들려 준다.
- 고른 버튼은 보라색. 바꾸는 즉시 적용, 닫을 때 저장.
- 허브는 창이 닫히면 화면 흔들림 버튼을 다시 그린다(같은 값 공유).

### 조작법 (`ControlsPanel` · `ControlsCatalog`)

코드에서 실제로 읽는 키와 대조해 표를 만들었다.

| 분류 | 동작 | 키 |
| --- | --- | --- |
| 기본 | 이동 · 대시 · 층 이동 | WASD/방향키 · Shift/Space · F |
| 최면 | 최면 · 파동 · 회수 | 마우스 왼쪽/E · 오른쪽 유지 · 회수 지점으로 |
| 위기 | 붙잡힘 탈출 · 힘겨루기 | 왼쪽 · 오른쪽 번갈아 |
| 화면 | 카드 · 건너뛰기 · 지도 · 일시정지 | 클릭/숫자 · 클릭 · 숫자/Enter/Tab · Esc |

일시정지에서 열면 이번 장소 설명과 방해 세력을 아래에 붙인다.

`HypnosisCursorController`가 `SettingsApplier.Changed`를 받아 커서 그림을 새 크기로 다시 만든다. 스테이지 안에서 바꿔도 바로 적용된다.
