# 41일차 — 세계 시간 및 지역 위험 배율 시스템

## 구현

- 세계 시간을 아침 → 낮 → 저녁 → 밤 순서로 순환하도록 추가했다.
- 장소 8곳의 위험 배율을 각각 `×0.80`~`×1.40` 범위로 생성하고 저장하도록 구현했다.
- 장소 클리어 시에만 세계 시간을 진행하고 모든 지역 위험 배율을 다시 추첨하도록 연결했다.
- 실패·포기·불러오기에서는 현재 시간과 지역 위험 배율을 유지하도록 고정했다.
- 지역 위험 배율을 목표 정기, NPC 최면 저항, 경계도 상승, 특수 능력 재사용 대기, 계약 정기에 적용했다.
- 지도 장소 카드와 상세 패널, 장소 규칙 카드에 현재 세계 시간과 선택 지역 위험 배율을 표시했다.
- 기존 저장 자료는 아침과 중립 위험 `×1.00`으로 안전하게 보정하도록 저장 형식을 2버전으로 갱신했다.

## 적용 규칙

- 위험 배율이 높을수록 목표 정기·NPC 저항·경계도 상승·계약 보상이 증가한다.
- 위험 배율이 높을수록 방해 세력 특수 능력의 재사용 대기시간이 감소한다.
- 경계도를 낮추는 효과는 지역 위험 배율의 영향을 받지 않는다.
- 장소 고유 배경 정보는 안내에 남기고, 실제 스테이지 시간 연출은 저장된 세계 시간을 따른다.
