# 부록 B. 도시 지도 · 장소 확장 (구역 재편안)

본 부록은 부록 A.9의 "대형 스테이지 5구역(마도 아카데미·기숙사·상업지구·지하 마법구역)" 구성을 **현실 장소 기반의 해안 도시 지도**로 재편한 안이다.
장소마다 분위기 · 등장 NPC · 방해 세력 · 환경 규칙 · 대표 목표가 달라져, 같은 최면 시스템이라도 공략법이 달라지는 것을 목표로 한다.

등장인물은 기존 원칙대로 **전원 명확한 성인**이며, 모든 장소는 성인이 일하거나 여가를 보내는 현실의 공간으로 한정한다.

---

## B.1 설계 원칙

- 장소는 판타지 공간이 아닌 **현실의 장소**로 구성한다. 서큐버스·최면 등 오컬트 요소는 현실 장소 위에 겹쳐지는 형태로만 존재한다.
- **장소가 적과 규칙을 정한다.** 방해 세력은 그 장소에 실제로 있을 법한 인물·사물로 표현한다.
- 방해 세력은 **역할(감시 · 구출 · 쟁탈 · 길막 · 도둑 · 관문)** 을 공통 동작으로 먼저 만들고, 장소마다 외형과 수치만 바꿔 제작 부담을 줄인다.
- 시간대는 **낮 → 저녁 → 밤** 순서로 흘러, 한 판 안에서 도시의 하루가 지나가는 느낌을 준다.

---

## B.2 도시 지도

```
                     [7] 루프탑 클럽 (최종 · 밤)
                              │
   [6] 오피스 타워 ── [5] 쇼핑몰 ── [4] 야시장 (밤)
          │                │              │
   [0] 기업 연수원 ── [2] 지하철 환승역 ── [3] 헬스장·스포츠센터
   (시작 · 튜토리얼)       │
                     [1] 해변가 (낮)
```

- 지하철 환승역은 여러 장소를 잇는 **중앙 허브**다.
- 시작 구역은 현재 프로토타입의 층·복도 구조를 재활용한다 (B.3의 [0] 참고).

## B.3 장소 구성

### [0] 기업 연수원 (시작 · 낮) — 현재 프로토타입 재활용

| 항목 | 내용 |
| --- | --- |
| 분위기 | 대기업 신입·경력 사원 합숙 교육 시설. 강의실, 복도, 휴게실, 숙소동 |
| 여성 NPC | 신입 사원 교육생, 교육 담당 강사, 인사팀 매니저, 시설 관리 직원 |
| 방해 세력 | **교육 조교**: 복도를 순찰하며 최면 중인 사람을 발견하면 따라붙는다 (감시) |
| | **금태양 · 인기남**: 기존 라이벌 (쟁탈) |
| 환경 규칙 | **교육 시간표**: 쉬는 시간 종이 울리면 복도에 인원이 쏟아졌다가 빠진다. 붐빌 때 최면은 쉽지만 동행자가 뒤섞인다 |
| | **자습실**: 조용해서 달리기 · 대시 소리가 경계를 올린다 |
| 대표 목표 | 정기 할당량 (튜토리얼 구역: 최면 → 동행 → 회수 → 쟁탈 → 폭주 순 개방) |
| 비고 | 현재 구현된 4개 층 · 계단 · 회수 지점 구조를 그대로 사용한다 |

### [1] 해변가 (낮)

| 항목 | 내용 |
| --- | --- |
| 분위기 | 백사장, 파라솔, 매점, 샤워장. 밝고 탁 트인 여름 |
| 여성 NPC | 선베드의 관광객(수영복), 비치발리볼 선수, 서핑 강사, 매점 아르바이트생 |
| 방해 세력 | **라이프가드**: 망루에서 넓은 범위를 감시한다. 최면을 오래 유지하면 호루라기로 주변 NPC를 경계 상태로 만든다 (감시) |
| | **헌팅남**: 동행자에게 말을 걸어 데려가려 한다 (쟁탈) |
| 환경 규칙 | **밀물 · 썰물**: 주기적으로 파도가 들어와 바닷가 쪽 레인이 막힌다 |
| | **파라솔 그늘**: 그늘 안에서는 라이프가드의 시야가 끊긴다 |
| 대표 목표 | **동시 운반**: 흩어진 인원을 모아 샤워장(회수 지점)까지 한 번에 데려가기 |
| 재미 포인트 | 넓어서 최면은 쉽지만 숨을 곳이 적다 |

### [2] 지하철 환승역 (허브 · 저녁)

| 항목 | 내용 |
| --- | --- |
| 분위기 | 개찰구, 플랫폼, 에스컬레이터, 역 안 편의점 |
| 여성 NPC | 퇴근하는 직장인, 캐리어를 끄는 관광객, 역 안 카페 점원 |
| 방해 세력 | **역무원**: 개찰구를 막고, 동행자가 많으면 한 명씩만 통과시킨다 (관문 · 병목) |
| | **휴대폰만 보는 행인**: 시선이 휴대폰에 고정되어 최면이 걸리지 않으며 길을 막는다 (길막) |
| 환경 규칙 | **열차 도착**: 주기적으로 문이 열리며 군중이 한꺼번에 내리고 탄다. 이때 동행자가 휩쓸려 흩어질 수 있다 |
| 대표 목표 | **생존형**: 열차 3대가 지나갈 때까지 무리를 유지하기 |

### [3] 헬스장 · 스포츠센터 (저녁)

| 항목 | 내용 |
| --- | --- |
| 분위기 | 러닝머신 구역, 요가실, 실내 수영장, 탈의실 앞 복도 |
| 여성 NPC | 요가 강사, 필라테스 회원, 크로스핏 선수, 수영 코치 |
| 방해 세력 | **퍼스널 트레이너**: 담당 회원 곁에 붙어 있다가 최면이 시작되면 끼어들어 깨운다 (구출) |
| | **헬스 고인물**: 힘겨루기에 강한 라이벌 (각성형 라이벌) |
| 환경 규칙 | **심박**: 운동 중인 NPC는 최면이 빨리 차지만 충동도 빨리 오른다. 요가실 NPC는 느리게 차고 안정적이다 |
| 대표 목표 | **특수 대상**: 대회를 앞둔 선수(고저항 희귀 NPC) 함락 |

### [4] 야시장 (밤)

| 항목 | 내용 |
| --- | --- |
| 분위기 | 포장마차 노점 골목, 등불, 연기, 음악, 인파 |
| 여성 NPC | 노점 사장, 데이트 나온 손님, 버스킹 가수, 촬영 중인 인플루언서 |
| 방해 세력 | **호객꾼**: 동행자를 노점으로 끌어들여 멈춰 세운다. 방치하면 이탈한다 (쟁탈) |
| | **촬영팀**: 조명과 카메라를 들고 다니며, 조명에 비친 플레이어는 경계가 크게 오른다 (감시) |
| | **소매치기**: 동행자 대신 **아직 회수하지 않은 정기**를 훔쳐 달아난다. 쫓아가 되찾아야 한다 (도둑 · 신규 역할) |
| 환경 규칙 | **어둠과 등불**: 등불 아래에서만 최면 사거리가 온전하고, 어두운 곳은 사거리가 줄어든다 |
| | **좁은 골목**: 동행자가 한 줄로만 따라온다 |
| 대표 목표 | 정기 할당량 + 소매치기 저지 보너스 |
| 재미 포인트 | 가장 복잡하고 붐비는 장소. 인원 욕심과 줄서기 병목의 줄다리기 |

### [5] 쇼핑몰 (저녁)

| 항목 | 내용 |
| --- | --- |
| 분위기 | 에스컬레이터로 이어진 층, 명품관, 푸드코트, 피팅룸 앞 |
| 여성 NPC | 매장 매니저, 쇼핑 온 손님, 화장품 판매원, 촬영 중인 모델 |
| 방해 세력 | **보안요원**: 무전으로 연결되어, 한 명이 발견하면 층 전체의 보안요원이 모인다 (감시) |
| | **CCTV** (고정형): 시야 부채꼴 안에서 최면하면 보안요원을 부른다 (감시) |
| 환경 규칙 | **에스컬레이터**: 오르내리는 동안 멈출 수 없다 (층 구조 재활용) |
| | **폐점 방송**: 방송이 나오면 제한 시간이 빨리 흐른다 |
| 대표 목표 | 정기 할당량 + CCTV에 걸리지 않고 회수하면 잠입 보너스 |

### [6] 오피스 타워 (야근 시간)

| 항목 | 내용 |
| --- | --- |
| 분위기 | 칸막이 사무실, 회의실, 탕비실, 엘리베이터 |
| 여성 NPC | 팀장, 인턴, 비서, 야근 중인 디자이너 |
| 방해 세력 | **꼰대 부장**: 근처 직원에게 일을 시켜 최면 중인 NPC를 자리로 돌려보낸다 (최면 게이지 초기화 · 구출) |
| | **출입증 게이트**: 층마다 잠겨 있고, 특정 NPC(비서)를 최면해야 열린다 (관문 · 신규 역할) |
| 환경 규칙 | **엘리베이터 정원**: 동행자를 나눠 태워야 한다 |

| 대표 목표 | **특수 대상**: 최상층 대표 비서 함락 (게이트를 순서대로 열어야 함) |

### [7] 루프탑 클럽 (최종 · 밤)

| 항목 | 내용 |
| --- | --- |
| 분위기 | 도시 야경, 댄스플로어, VIP 라운지, 바 |
| 여성 NPC | 파티 손님, 바텐더, DJ, VIP 게스트 |
| 방해 세력 | **바운서**: 입구와 VIP 구역을 막고, 동행자가 많으면 입장을 거부한다 (관문) |
| | **라이벌 서큐버스**: 클럽을 자기 영역으로 삼은 최종 보스. 클럽 전체 손님을 두고 세력전을 벌인다 (12장) |
| 환경 규칙 | **음악 박자**: 비트가 떨어지는 순간(드롭) 최면 효율이 오르고, 동시에 모든 동행자의 충동도 오른다 |

## B.4 방해 세력 역할표

9장(방해 및 저항 세력)과 A.7(라이벌 3종)의 역할에 현실 장소의 외형을 입힌다.

| 역할 | 하는 일 | 기존 기획 대응 | 장소별 방해 세력 |
| --- | --- | --- | --- |
| 감시 | 오래 최면하면 경계 상승, 증원 호출 | 감시자 | 교육 조교, 라이프가드, 촬영팀, 보안요원, CCTV |
| 구출 | 최면 중이거나 동행 중인 NPC를 깨움 | 구출자 · 각성자 | 퍼스널 트레이너, 꼰대 부장 |
| 쟁탈 | 동행자를 데려감 | 유혹형 라이벌 | 금태양, 인기남, 헌팅남, 호객꾼 |
| 길막 | 길과 시야를 막음 | 방해형 라이벌 | 휴대폰만 보는 행인, 역무원 |
| 힘 대결 | 힘겨루기에 강함 | 각성형 라이벌 | 헬스 고인물 |
| 도둑 **(신규)** | 회수 전 정기를 훔침 | - | 소매치기 |
| 관문 **(신규)** | 조건을 채워야 통과 | - | 역무원, 출입증 게이트, 바운서 |
| 보스 | 세력전 | 라이벌 서큐버스 | 라이벌 서큐버스 |

결계술사(9.4)는 현실 장소 원칙에 맞춰 **환경 규칙(어둠 · 조명 · 소음 · 정전)** 으로 대체한다.

## B.6 한 판 구성 규칙 (초기안)

- 한 판은 **시작 구역(기업 연수원) → 무작위 장소 3곳 → 루프탑 클럽** 의 5구역으로 구성한다. A.9의 "대형 스테이지 1개 · 5구역" 원칙을 유지한다.
- 무작위 장소는 시간대 순서(낮 → 저녁 → 밤)를 지키도록 뽑는다.
- 장소 사이 이동은 지하철 환승역 연출로 처리하고, 환승역 자체가 뽑히면 생존형 구역으로 플레이한다.
- 첫 엔딩 전까지는 장소 해금 순서를 고정해 스토리 흐름을 보장하고, 이후 무작위 구성을 개방한다.

---

## B.7 제작 우선순위 (초기안)

1. **역할 공통 동작 먼저**: 감시 · 구출 · 쟁탈 · 길막 · 도둑 · 관문 6종을 공통 컴포넌트로 만든다.
2. **해변가**: 넓은 공간이라 새 규칙(파도 · 그늘)이 가장 적다.
3. **야시장**: 시각적으로 가장 다른 장소. 어둠 · 등불 규칙과 도둑 역할을 검증한다.
4. 이후 지하철역 → 헬스장 → 쇼핑몰 → 오피스 타워 → 루프탑 클럽(보스) 순으로 확장한다.

## B.8 결정 로그 추가 (30.2에 반영)

- 구역 구성을 판타지 지역(마도 아카데미 · 기숙사 · 상업지구 · 지하 마법구역)에서 **현실 장소 기반 해안 도시 8곳**으로 변경한다.
- 대학 캠퍼스안은 삭제한다.
- 시작 구역은 현재 프로토타입의 층 · 복도 구조를 재활용하되, 등장인물 전원이 성인임이 분명한 **기업 연수원**으로 설정한다.
- 방해 세력은 역할 6종(감시 · 구출 · 쟁탈 · 길막 · 도둑 · 관문) + 보스로 정리한다. 도둑 · 관문은 신규 역할이다.
- 결계술사는 환경 규칙(어둠 · 조명 · 소음 · 정전)으로 대체한다.
