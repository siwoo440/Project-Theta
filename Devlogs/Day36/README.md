# 36일차 - 학생의 방 허브 · 방 안 서큐버스 · 이야기 · 심야 모드 · 도시 지배도 구현

## 이번 일차의 목표

31일차 점검에서 남은 **"이야기 비중 · 엔딩 뒤 목표"**를 다뤘다. 여기에 허브 분위기 변경 요청을 함께 반영했다.

- 이야기가 처음 소개 5장과 엔딩 4줄뿐이라, 장소를 돌아도 이야기가 진행되는 느낌이 없었다.
- 엔딩 뒤에는 시작 카드 4장 말고는 계속할 이유가 약했다.
- 허브는 보라 단색 배경 위에 카드가 화면을 거의 다 덮고 있었고, 강화 카드는 항상 펼쳐져 있었다.

## A. 학생의 방 허브

### 방 그리기 (`UI/HubRoomBackdrop`)

그림 자산이 없어서 사각형과 흐린 원으로 그렸다. 그림이 생기면 이 파일만 바꾸면 된다.

```
  포스터        창문(밤하늘 · 별 · 달 · 도시 실루엣 · 불빛) + 커튼        벽시계
  책장          책상(노트 · 스탠드 · 연필꽂이) · 의자        협탁(일기장) · 침대
  ─────────────────────── 바닥 · 달빛 · 러그 ───────────────────────
```

- 창밖 불빛은 하나씩 천천히 깜빡이고, **도시 지배도만큼 보라색으로 물든다**(`SetDominion`).
- 스탠드 불빛이 약하게 일렁이고, 벽시계는 **실제 시각**을 가리킨다.
- 누를 수 있는 물건에 마우스를 올리면 보라 빛과 이름표가 서서히 뜬다(`UI/HubHotspot`).

| 물건 | 누르면 |
| --- | --- |
| 계약 노트 | 강화 창 |
| 벽시계 | 난이도 창 |
| 책장 | 통계 창 |
| 일기장 | 일기장 창 |
| 창문 | 지도로 출격 |

### 화면 구성 (`UI/HubScreen` 재구성, `UI/HubWindow`, `UI/HubRoomLogic`)

| 자리 | 내용 |
| --- | --- |
| 위 띠 | "학생의 방 · N번 칸" · 계약 정기 / 도시 지배도 % · 칭호 · 막대 / `업적` `조작법` `설정` |
| 아래 띠 | `강화` `통계` `난이도` `일기장` `저장` `타이틀로` · 저장 문구 · `출격 ▶` |
| 왼쪽 아래 | 직전 도전 결과가 있을 때만 작은 반투명 카드(심야면 ☾) |

| 창 | 내용 |
| --- | --- |
| 강화 · 계약 노트 | 보유 계약 정기, 4계열 성장 · 구매 |
| 통계 · 책장 | 누적 요약 3줄, 장소 8곳 지배도 내역, `업적 보기` · `자세한 통계`(지도와 같은 통계 창), 밸런스 자산 상태 |
| 난이도 · 벽시계 | 난이도 3버튼 · 설명 |
| 일기장 · 본 이야기 | 이야기 20칸. 본 것만 제목이 보이고, 누르면 대사 창으로 다시 재생 |

- 창은 한 번에 하나만 열리고, 열린 창의 버튼은 보라색이다. 닫기: 같은 버튼, `×`, 어두운 곳 클릭, Esc.
- 창 바탕 82%, 뒤 어둡게 25%, 띠 55% 불투명이라 방이 계속 보인다.
- 예전 설정 카드(흔들림 버튼 · 설정 더 보기 · 조작법)는 위 띠의 `설정` · `조작법`으로 합쳤다. 흔들림은 설정 창에서 바꾼다.

## D. 도시 지배도 (`Save/DominionLogic`)

- 장소마다 **클리어 1 + 숙련 ★ 최대 3 + 심야 클리어 1 = 5점**, 8곳 40점 만점. %는 내림이라 40점을 모두 채워야 100%다.

| 지배도 | 칭호 |
| --- | --- |
| 0% | 신참 서큐버스 |
| 25% | 밤거리 단골 |
| 50% | 뒷골목 실세 |
| 75% | 도시의 그림자 |
| 100% | 도시의 주인 |

- 표시: 허브 위 띠, 통계 창 장소별 내역("클리어 ✓ · ★★☆ · ☾ ✗ 3/5"), 창밖 불빛, 저장 칸 요약 셋째 줄.
- 100%면 후일담 「도시의 주인」이 나온다.
