# 22일차 - 방해 세력 공통 시스템 및 구역 경계도 구현

## 이번 일차의 목표

21일차에 5구역 한 판 흐름을 만들었지만, 장소에는 아직 **플레이어를 막는 존재가 경쟁자(금태양)뿐**이었다.
부록 C에서 장소마다 방해 세력 27종 · 특수 능력 11종을 기획했으므로, 오늘은 그것들을 올릴 **공통 틀**을 만들고
첫 장소인 **기업 연수원**에 실제 적 2종과 환경 규칙 2개를 넣었다.

1. 적 하나를 **설정표 + 역할 + 특수 능력**으로 조립하는 틀
2. 구역 전체가 공유하는 **경계도** (평온 → 주의 → 경계 → 비상)
3. 연수원 적 **교육 조교 · 인사팀 평가관**, 규칙 **쉬는 시간 종 · 자습실**

---

## 기획 결정

### 걷기만 하면 들키지 않는다

"시야에 들어오면 발각"으로 하면 복도를 걷는 것 자체가 벌이 된다.
그래서 **보는 앞에서 최면을 걸거나 대시할 때만** 의심이 쌓이게 했다. 들키지 않으려면 **시야를 피해 최면을 거는 판단**이 필요하다.

### 특수 능력은 반드시 예고한다

모든 특수 능력은 **예고 → 발동 → 재사용 대기** 순서를 거친다. 예고 시간은 설정값과 상관없이 **최소 1초**로 강제해서
"보지도 못하고 당하는" 상황을 막았다.

### 파동이 대응 수단

우클릭 파동에 맞은 적은 **3초 멍함(zZ)** 상태가 되고, 감시자가 맞으면 경계도가 **15 내려간다**.
들킨 뒤에도 되돌릴 방법이 있어야 긴장이 좌절로 바뀌지 않는다.

## A. 구역 경계도

| 단계 | 경계도 | 효과 |
| --- | --- | --- |
| 평온 | 0 ~ 29 | - |
| 주의 | 30 ~ 59 | 순찰 속도 ×1.2, 플레이어 최면 속도 ×0.9 |
| 경계 | 60 ~ 89 | 마지막 발견 지점 확인(6초마다), 특수 능력 재사용 ×0.7 |
| 비상 | 90 ~ | 조교 증원(한 구역 최대 2회), 회수 지점 10초 잠금, 경계도 60으로 내려감 |

| 오르는 경우 | 양 |
| --- | --- |
| 들킨 채 최면 | 초당 12 |
| 들킨 채 대시 | 1회 8 |
| 자습실 안에서 대시 | 1회 10 |

- 오르지 않은 프레임에는 **초당 4씩 감소**
- HUD 중상단에 경계도 막대와 단계 이름, 잠금 중에는 "회수 지점 잠김 N초"
- 단계가 **오를 때만** 연출 (비상은 화면 흔들림 + 도장 효과음)

## B. 방해 세력 구조

```
DisruptorSpawner ─ 장소별 배치표를 읽어 생성
   └ 적 1명
       ├ DisruptorBase      순찰 · 멍함 · 방향 · 층 (공통 몸체)
       ├ WatcherRole        의심 ? → 발각 ! → 추적 (역할)
       ├ SpecialAbility     예고 → 발동 → 대기 (특수 능력 틀)
       └ DisruptorStatusView 이름표 · 상태 글자 · 예고 막대 · 시야 부채꼴
```

- 역할 7종(감시 · 구출 · 쟁탈 · 길막 · 힘 대결 · 도둑 · 관문)은 이름을 정의했고, 오늘은 **감시**만 동작한다
- 시야 판정은 2.5D 평면의 부채꼴이라 **줄(레인)을 바꿔 시야를 피할 수 있다**
- 발각까지 0.8초, 동행자가 많을수록 조금 빨라짐

## C. 기업 연수원

| 적 | 배치 | 특징 |
| --- | --- | --- |
| 교육 조교 | 층마다 1명 | 복도 ±6 순찰, 시야 30° · 6m |
| 인사팀 평가관 ◆ | 3F · 4F | 제자리에서 좌우 번갈아 보기, 시야 45° · 8m, 특수 능력 **근태 체크** |

**근태 체크** — 시야 안 동행자에게 1.2초 예고 뒤 표식(10초)

- 유지도 감소 2배 + 초당 4 감소
- 표식 중 회수하면 정기 20% 감소
- 재사용 대기 12초

| 규칙 | 내용 |
| --- | --- |
| 쉬는 시간 종 | 40초마다 울리고 8초 동안 NPC 이동 ×1.6 |
| 자습실 | 2F ~ 4F에 하나씩. 안에서 대시하면 "쉿!" + 경계도 10 |

## 판단한 것

### 1. 근태 체크에 고정 감소를 더함

유지도는 플레이어 가까이 있으면 회복만 해서, "감소 2배"만으로는 곁에 둔 동행자에게 아무 영향이 없었다.
표식 동안 **초당 4씩 줄게** 해서(10초 최대 40) 가까이 있어도 손해가 보이게 했다.

### 2. 순찰 범위 밖이면 걸어서 돌아감

증원 · 추적으로 범위를 벗어난 적을 범위 안으로 순간 이동시키지 않고 **걸어서 복귀**하게 했다.

### 3. 임시로 둔 것

| 항목 | 처리 |
| --- | --- |
| 적 외형 | 조교는 금태양, 평가관은 여성 NPC 스프라이트에 색만 입힘 |
| 나머지 6개 역할 | 그 역할을 처음 쓰는 장소를 만드는 날에 구현 |
