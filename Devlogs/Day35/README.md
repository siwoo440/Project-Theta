## 이번 일차의 목표

31일차 점검에서 남은 **"장소 규칙 안내 · 추천 순서 · 첫 소개 화면"**을 다뤘다.

- 장소 8곳의 규칙이 모두 다른데, 지도에는 한 줄 소개와 적 이름만 있었다.

지도는 참고 이미지처럼 **"장소를 고르면 오른쪽에서 패널이 들어오고, 정보는 버튼으로 나눠 보는"** 구성으로 바꿨다.

## A. 장소 안내 데이터 (`Stage/Locations/LocationGuideCatalog`)

장소마다 난이도(1~5), 규칙 3~4줄, 적 2~4종(이름 · 하는 일 · 대처), 공략 팁 2줄을 담았다.
23~26일차 장소 규칙 코드와 방해 세력 배치표를 읽고 **실제 동작대로** 적었다.

| 장소 | 난이도 | 규칙 요약 |
| --- | --- | --- |
| 기업 연수원 | ◆ | 쉬는 시간 종 · 자습실 대시 경계도 |
| 해변가 | ◆◆ | 동시 운반 ×1.2/×0.5 · 밀물 · 파라솔 그늘 |
| 지하철 환승역 | ◆◆ | 열차 · 개찰구 · 증원 없음 |
| 헬스장 | ◆◆◆ | 운동 구역 · 요가실 · 선수 +60 |
| 야시장 | ◆◆◆ | 어둠 사거리 ×0.7 · 좁은 골목 · 증원 없음 |
| 쇼핑몰 | ◆◆◆◆ | 잠입 ×1.3 · 폐점 방송 · 기둥 · 보안실 직원 |
| 오피스 타워 | ◆◆◆◆ | 출입증 게이트 · 정전 · 엘리베이터 4명 · 대표 비서 +80 |
| 루프탑 클럽 | ◆◆◆◆◆ | 세력 1.2배 · 드롭 · VIP 입구 · 정신력 |

- `RivalsAppear`: 루프탑 클럽은 장소 표에 경쟁자가 켜져 있지만 부트스트랩이 금태양 · 인기남을 만들지 않는다. 그래서 안내에서도 경쟁자를 빼고 "경쟁자 없음"으로 보여 준다.

## B. 안내 문구 · 추천 (`UI/LocationGuideLogic`)

| 기능 | 내용 |
| --- | --- |
| `GetRecommended` | 아직 클리어하지 않은 장소 중 난이도가 가장 낮은 곳 → 목표 정기가 낮은 곳 → 앞 순서. 모두 깼으면 없음 |
| `IsFirstVisit` | 이 칸의 장소 기록 도전 수가 0이면 첫 입장 |
| `BuildCoreRows` | 제한 시간 · 목표 정기 / 층 · 경쟁자 / 숙련 |
| `BuildEnemyText` | 적마다 이름 · 하는 일 · 대처(초록 글자) |
| `BuildRuleText` | 목표 방식(정기 + 탈출 / 열차 생존 / 보스 함락) · 이 장소의 규칙 · 공략 팁 |
| `BuildRewardText` | 계약 정기 계산(클리어 · 등급 보너스 · 실패 50% · 포기 0), 숙련 단계와 다음 ★까지, 이 장소의 업적 |
| `BuildRecordText` | 도전 · 클리어(비율) · 최고 등급 · 최고 정기 · 최단 클리어 · 다음 ★ |

수치는 밸런스 값 · 숙련도 상수 · 실패 배율을 그대로 읽어, 값을 바꾸면 문구도 따라 바뀐다.

## C. 지도 오른쪽 패널 (`UI/MapScreen`)

```
 장소를 고르지 않음                 장소를 고름
┌──────────────────────────┐      ┌───────────────┬──────────┬──────────────┐
│        지도(가운데)        │  →   │ 지도(왼쪽)     │ 상세 창   │ 패널          │
└──────────────────────────┘      └───────────────┴──────────┴──────────────┘
```

- 패널(폭 540): 시간대 · 목표 | 난이도 / 큰 번호 "05" · 이름 / 소개 / 핵심 수치 3줄 / 추천 문구(깜빡임) / `적 정보` `장소 규칙 (Tab)` `보 상` `기 록` / 보유 계약 정기 / `닫 기` `출 발 ▶`.
- 패널은 0.25초 동안 오른쪽에서 밀려 들어오고, 지도는 가운데에서 왼쪽으로 비킨다. 지도를 처음 열 때는 미끄러지지 않고 바로 제자리에 둔다.
- 상세 창(폭 480)은 패널 왼쪽에 붙고 한 번에 하나만 뜬다. 누른 버튼만 보라색이고, 같은 버튼이나 `×`를 누르면 닫힌다.
- 장소 칸 둘째 줄을 "난이도 ◆◆◇◇◇ · 시간대"로 바꿨다(목표 방식은 패널에서 본다).
- 추천 장소 칸 위에 금색 "◆ 추천" 표시가 깜빡인다.
- 지도를 처음 열면 방금 도전한 장소, 없으면 추천 장소를 골라 둔다.
- Tab: 장소를 골랐으면 장소 규칙 열고 닫기, 아니면 통계. Esc: 상세 창 → 패널 순서로 닫는다. 통계 버튼 글자는 `통  계`로 바꿨다.
- 예전의 "등장하는 방해 세력" 글과 내 기록 글은 상세 창(적 정보 · 기록)으로 옮겼다.

## D. 장소 안 규칙 카드 (`UI/LocationGuidePanel`)

- 이 저장 칸에서 처음 도전하는 장소면 로딩 · 시작 카드 선택 · 엔딩이 끝나고 판이 흐를 때 한 번 뜬다.
- 왼쪽에 목표 · 규칙 · 팁, 오른쪽에 적 정보를 보여 준다. 열려 있는 동안 `GameplayPause`로 게임이 멈춘다.
- Enter · Esc · `확인`으로 닫는다. Space는 대시와 겹칠 수 있어 쓰지 않는다.
- 일시정지 메뉴에 `장소 규칙` 버튼을 추가했다(계속하기 · 장소 규칙 · 조작법 · 설정 · 포기하기). 카드는 메뉴 위(정렬 270)에 뜨고, Esc를 누르면 카드만 닫힌다.
- 일시정지 메뉴가 카드를 찾아 쓰므로 부트스트랩에서 카드를 먼저 만든다.

## E. 첫 소개 화면 (`UI/IntroLogic`, `UI/IntroSequence`)

| 장 | 제목 |
| --- | --- |
| 1 | 인간 세상에 내려온 서큐버스 |
| 2 | 정기 |
| 3 | 최면과 동행 |
| 4 | 방해하는 사람들 |
| 5 | 도시의 정점으로 |

- `처음부터` → 칸 선택 → 새 게임 저장 → **소개** → 허브. 이어하기는 소개 없이 바로 허브로 간다.
- 화면 클릭 · Space · Enter로 넘긴다. 글자가 떠오르는 중에 누르면 먼저 다 보여 준다. Esc · `건너뛰기`로 끝낸다. 마지막 장 버튼은 "시작하기 ▶"다.
- 그림 자산이 없어 배경색 · 빛 알갱이 · 큰 글자로만 보여 준다. 나중에 그림을 넣을 자리(`_art`)를 비워 뒀다.
- 메인 메뉴 아래 줄을 설정 · 업적 · **소개** · 종료로 바꿨다.
