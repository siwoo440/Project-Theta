# 29일차 - 판 개념 제거 · 플레이 통계 · 보스 엔딩 구현

## 이번 일차의 목표

처음 제안은 "한 판 종료 화면 + 짜인 경로 복귀"였지만, 방향을 바꿨다.

| 제안 | 결정 |
| --- | --- |
| 한 판 종료 화면 | **하지 않음** |
| 짜인 경로(연수원 → 후보 2곳 ×3 → 클럽)로 복귀 | **하지 않음** |
| — | **"판" 개념 자체를 없애고 계속 진행** |
| 기록 남기기 | **지도에 [통계] 버튼 → 여러 요소를 숫자로 기록** |
| 보스 엔딩 연출 | 그대로 진행 |

---

## 기획 결정

### 판이 없는 흐름

```
허브 ⇄ 지도 ⇄ 장소 (8곳 중 아무 곳이나, 몇 번이든)
```

- 구역 번호 · 5구역 제한 · 판 포기 · 한 판 종료가 모두 사라졌다.
- 실패해도 끝나지 않는다. 결과 화면에서 `지도로` 또는 `허브로`를 고른다.

### 레벨 · 카드는 장소마다 새로 시작 (선택지 ①)

판이 없어지면 레벨 · 강화 카드를 언제 초기화할지 정해야 했다.

| 선택지 | 결과 |
| --- | --- |
| **① 장소마다 새로 시작** | **채택.** 장소마다 난이도가 일정하고, 영구 성장은 허브 강화(계약 정기)로만 한다 |
| ② 허브로 갈 때 초기화 | 판과 비슷한 흐름이 남아 제외 |
| ③ 계속 누적 | 오래 할수록 너무 쉬워져 제외 |

출발할 때마다 `GameSession.BeginLocation`이 새 도전을 만들어 Lv 1 · 카드 0장 · 시작 계약 카드부터 시작한다.

### 구역 번호 대신 장소 단계

예전에는 뒤 구역일수록 같은 층에도 고급 NPC가 더 섞였다.
이제 `RunRouteLogic.GetTier`가 **연수원 0 · 낮 1 · 저녁 2 · 밤 3 · 클럽 4**를 돌려주고, 그 값이 구역 번호 자리를 대신한다.

## B. 플레이 통계

### 저장

- `SaveData.Stats`(`PlayStats`) — 전체 누적
- `SaveData.LocationRecords`(`LocationStats[]`) — 장소별 도전 · 클리어 · 최고 정기 · 최단 클리어 · 최고 등급
- 예전 세이브는 `PlayStatsLogic.Normalize`가 빈 기록으로 채운다. 중복 · 빈 장소 기록은 정리한다.

### 흐름

1. 결과 화면이 `RunStatsRecorder`의 숫자(최면 · 동행 · 폭주 · 포획 · 힘겨루기 · 레벨업)와 카드 수 · 보스 함락 여부를 `StageResultSummary`에 담는다.
2. 같은 도전은 `RunSession.MarkRecorded`로 한 번만 넘긴다.
3. 스테이지를 떠날 때 `SaveDataLogic.ApplyStageResult`가 기존 기록과 함께 `PlayStatsLogic.Apply`로 통계를 더한다.
4. **치트를 쓴 도전은 통계에서 뺀다.** 계약 정기 · 허브 기록은 예전처럼 반영한다.

- 최대 동행자 수는 새로 센다(`RunStats.MaxFollowers`, 매 프레임 동행자 수 확인).

### 통계 창 (`StatsPanel`)

| 분류 | 항목 |
| --- | --- |
| 전체 | 총 플레이 시간, 장소 도전, 클리어, 클리어율, 엔딩(보스 함락) |
| 최면 · 동행 | 최면 성공, 최대 동행자, 회수한 동행자, 빼앗긴 동행자, 되찾은 동행자 |
| 정기 | 회수한 정기, 계약 정기, 한 번에 가장 많이 |
| 위기 | 폭주 예고, 폭주 버팀, 붙잡힘, 힘겨루기 승리 |
| 성장 | 레벨업, 고른 강화 카드 |
| 장소별 표 | 8곳 × 도전 · 클리어 · 최고 정기 · 최단 클리어 · 최고 등급 |

- 지도에서 버튼 또는 Tab으로 열고 Esc · Tab · 닫기로 닫는다. 열린 동안 지도 단축키는 멈춘다.
- 같은 프레임에 닫혔다 다시 열리지 않게 `LastToggleFrame`으로 막는다.

## C. 보스 엔딩

| 시각 | 연출 |
| --- | --- |
| 0.0초 | 함락 연출(빛기둥 · 흔들림) |
| 1.2초 | 화면이 어두워짐 |
| 2.0초 | 금색 "ENDING", 문장 4줄이 1.4초 간격으로 |
| 7.6초 | 1.6초 머문 뒤 걷힘 |
| 9.8초 | 결과 화면 |

- 시간표는 `EndingLogic`, 화면은 `EndingSequence`(클럽 규칙에 붙음).
- 문장이 뜨는 중에 클릭 · Space · Enter로 걷히는 단계로 건너뛴다.
- 엔딩이 도는 동안 `StageResultPanel`이 기다린다. 엔딩 횟수는 통계에 더한다.
