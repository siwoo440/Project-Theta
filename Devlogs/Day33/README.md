# 33일차 - 목표 달성 뒤 탈출 · 목표 정기 조정 · 밸런스 보고서 구현

## 이번 일차의 목표

31일차 점검에서 가장 급한 문제로 뽑은 **한 장소 플레이 길이**를 다뤘다.

| 장소 | 제한 시간 | 에디터 기록상 끝난 시간 |
| --- | --- | --- |
| 오피스 타워 | 200초 | 26초 |
| 기업 연수원 | 180초 | 28~49초 |
| 해변가 | 180초 | 34초 |
| 쇼핑몰 | 190초 | 46초 |
| 루프탑 클럽 | 210초 | 81초 |

목표 정기를 채우는 순간 곧바로 클리어되고 목표도 최면 6명 정도면 채워져서,
적 증가 · 폭주 · 강화 카드(대부분 레벨 1~2) · 숙련도가 작동하기 전에 끝났다.

## 기획 결정

| 질문 | 결정 |
| --- | --- |
| 한 장소 목표 플레이 시간 | **약 2~3분** |
| 목표를 채우면? | 곧바로 끝나지 않고 **탈출 가능** 상태 |
| 탈출 위치 | **1F 회수 지점** (상호작용 키) |
| 목표 달성 뒤 시간이 끝나면? | **클리어** |
| 적용 장소 | 생존형(지하철) · 보스형(클럽)을 뺀 **6곳** |

- 코드를 보니 연수원 · 해변가 · 헬스장 · 야시장 · 쇼핑몰 · 오피스가 모두 "정기 목표 달성 = 즉시 클리어" 규칙이라 6곳 전부에 적용했다.
- 점수는 정기 1당 10점, 남은 시간 1초당 20점이다. 기록상 초당 정기 약 9를 모으므로 1초 더 머물면 약 +90 / −20점이라 **남아서 더 모으는 쪽이 이득**이다. 점수식은 그대로 뒀다.

## A. 탈출 규칙 (`Stage/StageExitLogic`)

```
정기 모으기 ─ 목표 달성 (ExitReady) ─┬─ 1F 회수 지점에서 [F] → Cleared (Escaped)
                                     ├─ 제한 시간 끝        → Cleared (TimeUp)
                                     └─ 쓰러짐              → FailedByHealth
```

- `StageState.ExitReady`를 **맨 뒤에** 추가해 기존 번호(0~4)를 유지했다.
- `StageSessionController.IsRunning`에 탈출 가능 상태를 포함했다. 적 · 타이머 · 회수 · 카드가 그대로 돈다.
- `RequestExit()`: 남은 회수 묶음을 먼저 확정한 뒤 탈출한다(마지막으로 데려온 동행자도 정기에 들어감).
- `ExitKind`(Escaped · TimeUp · None), `SecondsAfterGoal`(목표 뒤 머문 시간)을 기록한다.
- 열차 · 보스가 없는 곳의 목표 보정 코드를 `ResolveObjective()`로 뺐다.
- 디버그 치트 `장소 즉시 클리어`는 목표를 채운 뒤 바로 탈출까지 한다.

## D. 밸런스 보고서 (`Run/BalanceReportLogic`)

- F1 → 기록 탭 → **`보고서 만들기`**: 기록 폴더의 json을 모두 읽어 `report.md`를 쓴다.
- 장소별: 기록 수 · 클리어율 · 탈출률 · 평균 · 최소~최대 시간 · 목표 뒤 머문 시간 · 평균 정기 / 목표 · 최면 · 레벨 · 폭주 예고 · 빼앗김.
- 치트 기록 · 장소 이름 없는 옛 기록은 빼고 개수만 적는다. 깨진 파일은 건너뛴다.
- 기록 파일(`RunLogEntry`)에 `Exit` · `TargetEssence` · `SecondsAfterGoal`을 추가했다.
