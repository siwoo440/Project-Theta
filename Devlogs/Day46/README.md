# 46일차 — 로비 대사·관계 대사·일기장 확장

Google 기획서의 `LOBBY_*` 대사 58종을 데이터화하고 허브 상태와 연결했다.

---
## 적용 내용

- 허브 입장·25초 방치·출격·등급별 귀환·실패·강화 대사 연결
- 폭주·동행자 탈취·장소 숙련·반복 클리어·도시 지배·심야 조건 우선 처리
- 르미아 조우 이후 라이벌 대사와 리엘라 H04 이후 관계 대사 해금
- 일반 상태 5% 희귀 대사와 직전 대사 즉시 반복 방지
- 확인한 대사 ID와 직전 대사 ID의 저장·복제·구버전 보정
- 씬 전환 중 소비된 결과를 허브에 한 번만 전달하는 귀환 결과 전달함
- 출격 대사 완료 콜백 보호와 일기장 하단 버튼 겹침 방지
- 일기장을 이야기/로비 대사 탭으로 분리하고 20개 단위 페이지 적용
- 확인하지 않은 로비 대사는 `？？？`로 숨기고 확인한 대사는 재생 허용

---
## 대사 우선순위

1. 기존 스토리 이벤트
2. 폭주·탈취·숙련·도시 진행 등 특수 진행
3. 직전 출격 결과와 등급
4. 성장 가능·심야·라이벌·관계 상태
5. 입장·방치 일반 대사와 희귀 대사
