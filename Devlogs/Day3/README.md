# Project θ 개발 일지 — 3일차

## 개발 목표

2일차에 구축한 플레이어 이동 및 학교 복도 테스트맵 위에 실제 캐릭터 이미지를 적용하고, 여학생 NPC의 기본 AI와 최면 기본 시스템을 구현했다.

3일차 목표는 다음 흐름을 실제 플레이 화면에서 확인할 수 있도록 만드는 것이었다.

```text
NPC 생성
→ Idle / Move
→ 플레이어 접근
→ Alert
→ 최면 대상 선택
→ 최면 게이지 상승
→ 최면 완료 표시
```

## 캐릭터 그래픽 적용

기존 테스트용 단색 사각형을 실제 캐릭터 이미지로 교체했다.

### 플레이어

- Idle 이미지 적용
- Move 4프레임 적용
- 이동 중 보행 애니메이션 재생
- 좌우 이동 방향에 따라 Sprite 좌우 반전
- 기존 Rigidbody2D 이동 및 Depth Sorting 유지

### 여학생 NPC

- Idle 이미지 적용
- Move 4프레임 적용
- 학교 복도에 여학생 NPC 10명 배치
- 이동 방향에 따라 Sprite 좌우 반전
- Depth Sorting 적용

## NPC 기본 AI

여학생 NPC에 기본 상태 시스템을 추가했다.

### Idle

- 일정 시간 정지
- 약 0.8~2.2초 대기 후 이동 상태로 전환

### Move

- 학교 복도의 이동 가능 범위 안에서 임의 목적지를 결정
- 목적지까지 이동
- 도착하면 다시 Idle로 전환

### Alert

- 플레이어가 약 3.2 거리 안으로 접근하면 Alert 전환
- Alert 상태에서 플레이어 방향을 바라봄
- 약 4.2 거리 밖으로 벗어나면 다시 이동 상태로 복귀
- 상태 확인을 위해 임시 색상 피드백 적용

## 최면 기본 시스템

플레이어가 여학생 NPC를 최면 대상으로 지정할 수 있는 기본 흐름을 구현했다.

입력:

- E 유지
- 마우스 왼쪽 버튼 유지

대상 판정 기준:

- 최대 거리 약 4.5
- Y축 차이 약 2.4 이내
- 플레이어가 바라보는 방향에 위치
- 조건을 만족하는 NPC 중 가장 가까운 대상 우선

최면 입력을 유지하면 대상 NPC의 최면 수치가 상승한다.

초기값:

- 최대 최면 수치: 100
- 상승 속도: 초당 32

## 최면 상태 표시

최면 진행 상태를 화면에서 바로 확인할 수 있도록 NPC별 시각 피드백을 추가했다.

### 보라색 최면 게이지

- 여학생 NPC 하단에 표시
- 최면 진행도에 따라 보라색 막대가 차오름
- 0~100% 진행 상태를 NPC 위치에서 직접 확인 가능

### 최면 완료 하트

- 최면 수치가 100%에 도달하면 NPC를 최면 완료 상태로 변경
- 최면 완료 NPC의 머리 오른쪽 위에 하트 아이콘 표시
- 이미 최면 완료된 NPC는 다시 최면 대상으로 선택하지 않음

- E 또는 마우스 왼쪽 버튼을 놓으면 동전 커서로 복귀

## 커서 경고 수정

초기 커서 구현에서는 Unity가 불러온 PNG를 `Cursor.SetCursor`에 직접 전달하면서 다음 조건을 만족하지 못해 경고가 발생했다.

- RGBA32
- Readable
- Alpha
- MipChain 없음

원본 커서 텍스처의 Import 설정에 의존하지 않도록 수정했다.

현재는 다음 순서로 커서 전용 Texture2D를 생성한다.

```text
Resources 원본 이미지
→ RenderTexture 복사
→ RGBA32 Texture2D 생성
→ MipMap 생성 안 함
→ CPU Read/Write 가능 상태 유지
→ Cursor.SetCursor
```

생성된 런타임 커서 Texture는 오브젝트 제거 시 함께 정리하도록 구성했다.

## 현재 완료 범위

3일차에서는 NPC 기본 AI와 최면의 기본 대상 선택 및 진행 상태 표현까지 구현했다.

아직 동행 시스템은 연결하지 않는다.

다음 개발에서는 다음 흐름을 구현한다.

```text
최면 완료
→ NPC 동행 시작
→ Follow
→ 동행 슬롯
→ 거리 이탈
→ 동행 상태 관리
```
