# 19일차 - 연출·효과음 임시 에셋 제작 및 집중력 개편

## 이번 일차의 목표

18일차까지 게임 규칙은 한 판이 끝까지 돌 만큼 갖춰졌다.
그런데 최면에 성공해도, 정기를 회수해도, 레벨이 올라도 **숫자만 바뀌고 화면은 조용했다.**
"했다"는 손맛이 없으니 규칙이 맞게 돌아도 재미를 판단하기 어려웠다.

아직 만들어 둔 그림·소리 에셋이 없었으므로, 이번 일차는

1. **임시 에셋을 코드로 직접 만들어 정식 에셋 자리에 넣고**
2. **게임의 중요한 순간마다 연출과 효과음을 붙이고**
3. 플레이 중 드러난 **집중력 때문에 게임이 늘어지는 문제를 고치는 날**이었다.

임시 에셋은 나중에 같은 이름의 진짜 파일로 **덮어쓰기만 하면** 코드 수정 없이 교체된다.

### .meta 파일

- 이미 있는 파일은 **기존 GUID를 유지**한다. 스크립트를 다시 돌려도 연결이 끊기지 않는다
- 그림은 프로젝트의 스프라이트 설정을 본떠 **Sprite(Single)** 로 가져오게 했다

### 파일이 없을 때

`VfxLibrary`는 `Sprite` → `Texture2D`를 스프라이트로 변환 → **코드로 만든 대체 그림** 순서로 찾는다.
`GameAudio`도 파일이 없으면 기존 합성음으로 떨어진다. 에셋이 빠져도 게임은 멈추지 않는다.

대신 조용히 대체로 떨어지면 알아채기 어려워서, **키 이름마다 파일이 있는지 보는 테스트**(`VfxAssetPresenceTests`)를 두었다.

## B. 연출 체계

### 구조 — 규칙 코드는 알림만 보낸다

```
게임 규칙 (최면·회수·폭주·포획·힘겨루기)
        │  StageMoments.Raise...(위치)
        ▼
StageVfxDirector  ── 연출을 고르는 유일한 곳
        │
        ▼
GameVfx (그림·글자)   CameraShake (흔들림)   GameplayPause (멈칫)   GameAudio (소리)
```

규칙 코드는 "최면 성공했다, 여기서" 한 줄만 보낸다. **연출을 바꾸거나 빼도 규칙 코드는 건드리지 않는다.**

| 새 파일 | 역할 |
| --- | --- |
| `Stage/StageMoments.cs` | 순간 알림 6종 (최면 성공, 회수 확정, 폭주 준비, 폭주 회피, 포획, 힘겨루기 승리) |
| `Presentation/StageVfxDirector.cs` | 알림 → 연출·효과음 연결 |
| `Presentation/GameVfx.cs` | 파문·빛·빛기둥·팝·파편·떠오르는 글자·날아가는 글자·페이드·위험 표시. **풀링** (월드 96개, 글자 24개) |
| `Presentation/VfxLibrary.cs` | 그림 불러오기 + 대체 그림 |
| `Presentation/VfxCurves.cs` | 크기·투명도 곡선 (순수 계산, 테스트 가능) |
| `Presentation/CameraShake.cs` | 흔들림 계산 |
| `Presentation/TimeScaleLogic.cs` | 멈춤·멈칫 우선순위 계산 |

### 순간별 연출

| 순간 | 연출 | 소리 |
| --- | --- | --- |
| 최면 성공 | 보라 파문 + 하트 | 종소리 |
| 되찾기 성공 | 위 + 금색 파문 한 겹 더 + 파편 | 종소리 |
| 회수 확정 | 빛기둥 (많이 모을수록 굵어짐) + **정기 숫자가 HUD 게이지로 날아감**, 3명 이상이면 약한 흔들림 | 화음 |
| 경험치 20 이상 | 작은 `+XP` 글자 | — |
| 레벨업 | 금색 고리 + `LEVEL UP` + 멈칫 + 약한 흔들림 | 아르페지오 |
| 폭주 준비 | 붉은 파문 + `!` | — |
| 폭주 중 | 화면 가장자리 붉은 맥동 | — |
| 폭주 회피 | `회피!` + 파문 + 흔들림 | 휙 |

## C. 연출을 넣다가 막은 문제

### 1. 멈칫이 카드 화면을 풀어버린다

레벨업하면 **멈칫(시간 0.05배)** 이 걸리고 곧바로 **카드 화면(시간 0)** 이 뜬다.
멈칫이 끝나는 순간 "시간을 1로 되돌린다"고 하면, 카드를 고르는 중에 게임이 다시 돌아간다.

`TimeScaleLogic.Resolve`에서 우선순위를 한 곳에 정했다.

```
완전 멈춤 요청이 하나라도 있다  → 0
멈칫이 남아 있다               → 멈칫 배율
둘 다 없다                    → 1
```

멈칫끼리 겹치면 **더 긴 쪽 하나만** 남긴다. 체인 최면처럼 연달아 걸려도 멈칫이 길게 늘어나지 않는다.
멈칫 시간은 `unscaledDeltaTime`으로 줄여서, 느려진 시간에 멈칫 자체가 느려지지 않게 했다.

### 2. 흔들림이 카메라를 밀어낸다

카메라는 `SmoothDamp`로 플레이어를 따라간다. 흔들린 위치를 그대로 다음 프레임의 출발점으로 쓰면 흔들림이 누적되어 카메라가 옆으로 흘러간다.

`CameraFollow2D`에 **흔들리기 전 위치(`_basePosition`)** 를 따로 두고, 화면에 보여줄 때만 흔들림을 더한다.

```csharp
transform.position = _basePosition + CameraShake.Offset;
```

### 3. 화면 흔들림 끄기

흔들림은 사람에 따라 멀미를 일으킨다. 허브에 **설정 카드**를 추가해 흔들림만 끌 수 있게 했다.

- `SaveData.ScreenShakeDisabled` — 이름을 "꺼짐"으로 지었다. **예전 세이브에는 이 항목이 없어 false로 읽히는데, false가 "켜짐"이어야** 기존 플레이어 설정이 바뀌지 않는다
- 끄면 흔들림만 빠지고 파문·멈칫·소리는 그대로다

### 4. 층 이동 효과음 중복

`FloorTransitionController`가 직접 내던 `UiTick` 소리를 지우고, 도착음은 연출 담당이 내게 옮겼다.

## D. 집중력 개편

### 문제

집중력이 **너무 빨리 줄고, 0이 되면 최면 자체가 막혀서** 기다리는 시간이 길었다.
"집중력이 찰 때까지 멍하니 서 있는 시간"이 게임을 늘어지게 만들었다.

### 바꾼 규칙

| | 전 | 후 |
| --- | --- | --- |
| 집중력의 역할 | 최면을 **걸 수 있는지** 결정 | 최면을 **얼마나 빨리** 거는지 결정 |
| 집중력이 남아 있을 때 | 기본 속도 | **1.6배** |
| 집중력 0 | 최면 불가, 일정량 찰 때까지 대기 | **기본 속도로 계속** |

```csharp
// FocusLogic
public static float GetHypnosisSpeedMultiplier(float current, float bonus) =>
    current > 0f ? 1f + Mathf.Max(0f, bonus) : 1f;
```

- `PlayerFocus`에서 "탈진 상태"와 "회복 기준치" 개념을 지웠다
- `HypnosisCaster`의 집중력 검사를 지우고 체인 속도 배율에 집중력 배율을 곱했다
- 빼앗긴 NPC **되찾기에도 같은 배율**을 적용했다
- 가속 크기는 자산의 `FocusHypnosisSpeedBonus` (0.6)
- HUD 문구: `최면 가속 ×1.6` / `기본 속도`

### 함께 잡은 버그

`NpcCounterStrike`(NPC 반격)가 집중력을 `TrySpend`로 깎고 있었다.
`TrySpend`는 **가진 양이 모자라면 아무것도 하지 않으므로**, 집중력이 반격 피해보다 적으면 반격이 공짜였다.
`TakeDamage`를 새로 두어 모자라면 0까지 깎게 했다.

## E. 일반 최면 속도 1.3배

집중력 개편 후에도 기본 속도가 느리게 느껴져서 **플레이어 최면 전체에 곱하는 배율**을 추가했다.

`StageBalanceValues.PlayerHypnosisSpeedScale = 1.3`

| 등급 | 전 (초당) | 후 (초당) | 집중력 가속까지 |
| --- | ---: | ---: | ---: |
| 일반 | 40 | **52** | 83 |
| 숙련 | 24 | **31** | 50 |
| 희귀 | 14 | **18** | 29 |
| 특별 | 12 | **16** | 25 |
| 각성 | 8 | **10** | 17 |

- 등급 표를 하나씩 고치지 않고 배율 하나를 곱해서 **등급 간 비율이 그대로 유지**된다
- **되찾기에도 1.3배**. 한쪽만 빨라지면 쟁탈이 상대적으로 답답해진다
- 경쟁자 최면 속도는 그대로다
- 자산 값 하나라 재컴파일 없이 조정한다

## 판단한 것

### 1. 임시 에셋도 "정식 경로"에 넣었다

임시라고 별도 폴더에 두면 나중에 경로를 바꾸는 작업이 따로 생긴다.
처음부터 최종 파일 이름·위치에 두었으므로 **진짜 에셋이 나오면 파일만 덮어쓰면 된다.**

### 2. 연출은 규칙 밖에 두었다

연출 코드가 규칙 코드 안에 흩어지면, 연출을 조정할 때마다 규칙 코드를 열게 되고 버그가 섞인다.
규칙 쪽 변경은 **알림 한 줄씩**뿐이다.

### 3. 집중력은 "막는 자원"에서 "보너스 자원"으로

막는 자원은 떨어졌을 때 할 일이 없어진다. 보너스 자원은 떨어져도 게임이 계속되고, 아껴 쓸 이유만 남는다.
