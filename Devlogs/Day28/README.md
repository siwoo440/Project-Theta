## A. 로딩창

### 화면 구성

```
            (서큐버스)
               (주인공 →)
     [■■■■■■■■□□□□□□□□]  48%
                                   ┌ TIP ───────────────┐
                                   │ 도움말 한 줄        │
                                   └────────────────────┘
```

- **주인공**: `Characters/Player/Move_0~3`을 번갈아 보여 달린다. 가로 위치는 **로딩 바 진행률**을 따른다.
  바 왼쪽 끝(0%)에서 출발해 바가 차오르는 끝 위를 달리고, 100%에서 바 오른쪽 끝에 도착해 멈춰 선다.
- **서큐버스**: 주인공 왼쪽 위 자리를 지수 감쇠로 살짝 늦게 따라가며 위아래로 둥실거린다.
  `Characters/Succubus/Idle.png`가 없으면 날개 · 뿔 · 꼬리 실루엣으로 대신한다.
- **로딩 바**: 실제 진행률(Unity 0~0.9 → 0~1)을 초당 70%씩 따라가며 줄어들지 않는다.
- **TIP**: 14개 문장을 3초마다 바꾸고, 같은 문장이 연달아 나오지 않는다.

### 기획 결정 — 주인공 위치는 시간이 아니라 진행률

처음에는 시간에 따라 900px을 도는 방식이었는데, 로딩이 1.2~1.5초면 끝나 **왼쪽에서 조금 걷다가 사라지는** 모습이 됐다.
화면 전체 폭(1600px)으로도 바꿔 봤지만 너무 넓어, 최종적으로 **가운데 로딩 바 길이(`BarWidth` 560px)**를 기준으로 달리게 했다.
바 · 길 선 · % 글자 위치가 모두 `BarWidth`를 따른다.

### 전환 흐름

1. `GameSession.GoTo` → `LoadingScreen.Load` (연타 방지: 로딩 중이면 무시)
2. 로딩창을 한 프레임 그린 뒤 `LoadSceneAsync`, `allowSceneActivation = false`
3. 다 불러오고 · 최소 1.6초 · 바 100%가 되면 0.35초 서 있다가 활성화
4. 새 씬 부트스트랩이 지어질 때까지 한 프레임 기다린 뒤 0.25초 페이드

- 비동기 로딩 동안 이전 씬이 뒤에서 돌지 않게 `GameplayPause`를 걸고, 이전 씬이 사라지면 푼다.
- 모든 애니메이션은 unscaled 시간을 쓴다.

## B. 규칙 소품 색 맞추기

- `LocationProps.Theme`에 장소 테마를 담고(부트스트랩이 구역마다 설정), `LocationProps.Structure`로 구조물을 그린다.
- `MapPropTint.Apply`
  1. 원래 색을 장소 강조색 쪽으로 18% 섞는다.
  2. 바닥과 밝기 차이가 0.12보다 작으면 어두운 바닥은 밝게, 밝은 바닥은 어둡게 민다.
- 큰 불투명 구조물 위에는 강조색 테두리를 한 줄 두른다.
- 적용: 노점 카운터, 망루, 개찰 게이트 기둥, 탕비실, 입구 바 · DJ 부스 · 2층 바, 셔터 틀, 러닝머신.
- 경고등 · 어둠 · 보스 효과처럼 색에 의미가 있는 것은 그대로 둔다.

## C. 맵 최적화

| 전 (27일차) | 후 (28일차) |
| --- | --- |
| 줄눈 · 모래 알갱이 · 벽돌 · LED 칸을 오브젝트로 하나씩 (층당 최대 약 230개) | `FloorPatternLayout`이 사각형 목록만 만들고 `FloorPatternBaker`가 텍스처 한 장(912×199)에 구워 **오브젝트 1개** |

- `MapPainter.CreatedCount`로 층당 오브젝트 수를 세고, `MapBudget.MaxObjectsPerFloor = 180`을 넘으면 경고를 남긴다.
