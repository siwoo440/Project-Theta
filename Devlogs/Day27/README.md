# 27일차 - 보스 기술 마무리 · 장소별 맵 디자인 구현

## 이번 일차의 목표

26일차에 나눠 둔 **보스전 후반부**를 마무리하고, 지금까지 모든 장소가 학교 복도 모양이던 것을
**장소마다 배경 · 바닥 · 소품 · 계단 모양이 다른 맵**으로 바꿨다.

> 작업 폴더에 먼저 준비해 둔 27일차 보스 변경본이 있어, 26일차 커밋 기준으로 추가만 하는 변경인지 확인하고 읽어 본 뒤 적용했다.

## A. 보스 기술 3개

| 기술 | 시작 | 예고 | 효과 | 대처 |
| --- | --- | --- | --- | --- |
| 샴페인 타워 | 18초 | 1.5초 | 10초 동안 라이벌 손님 확보 2배 | 2F 바텐더 최면 시 즉시 붕괴 |
| 분신 댄서 | 25초 | 1초 암전 | 분신 2명(15초), 시선 피해 절반 | 그림자가 있는 쪽이 진짜, 파동 한 번에 소멸 |
| VIP 전용 구역 | 35초 | 1.5초 로프 | 가로 5m 안 최면 속도 절반(15초) | DJ가 멍하면 지속 시간 절반 |

- 수치는 `LateBossSkillValues`에 모으고 순수 로직(`BossSkillLogic`)으로 테스트했다.
- 최면 속도에 VIP 구역 배율을 곱한다(`HypnosisTarget`).
- 결과 화면 제목에 "라이벌 서큐버스 함락" / "보호막 N장 남음"을 붙였다.

## B. 오피스 엘리베이터 정원

- 층 이동 시 동행자는 **최대 4명**만 함께 탄다.
- 나머지는 20초 동안 아래층에서 기다리고(`ElevatorWait`), 그 사이 돌아오면 다시 따라오며 시간이 지나면 떠난다.

## C. 장소별 맵 디자인

### 원칙: 보이는 것만 바꾸고 판정은 그대로

- 이동 범위 벽, 계단 위치, 회수 지점, 벤치 · 자판기 충돌체는 **학교 복도와 같은 자리 · 같은 크기**로 고정했다.
- 꾸미기 소품은 모두 **충돌 없는 그림**이고, 벤치 · 자판기 자리는 장소에 맞는 모양(선베드, VIP 소파 등)만 덧그린다.
- 계단 · 회수 지점 · 장소 규칙 소품(노점, 망루, 셔터, 게이트, 탕비실, 회의실, DJ 부스, 바) 앞은 비워 두고, 테스트로 겹침을 막는다.

### 구조

| 파일 | 역할 |
| --- | --- |
| `Map/MapTheme` | 장소별 색 묶음 · 바닥 무늬 · 계단 모양 · 하늘 여부 |
| `Map/MapBaseLayers` | 벽/하늘, 바닥 무늬, 고정 충돌체, 앞쪽 띠, 천장 조명 |
| `Map/MapPainter` | 사각형 · 소품(캐릭터 정렬) · 글자 · 그라데이션 그리기 도구 |
| `Map/MapLayoutRules` | 비워 둘 자리 · 겹침 · 밝기 대비 규칙 |
| `Map/MapArtLibrary` | `Resources/Maps/{장소}/Background·Floor` 그림 교체 자리 |
| `Map/Decor/*` | 장소별 꾸미기 8개 + 선택 카탈로그 |

### 장소별 모습

| 장소 | 배경 · 벽 | 바닥 | 계단 |
| --- | --- | --- | --- |
| 기업 연수원 | 흰 벽, 강의실 문, 화이트보드 | 회색 카펫 | 계단 |
| 해변가 | 하늘 · 해 · 바다 · 요트 | 모래 · 파도 거품 | 나무 데크 |
| 지하철 | 흰 타일, 노선 띠, 스크린도어 | 타일 · 점자 블록 | 에스컬레이터 |
| 헬스장 | 콘크리트, 거울, 2F 수영장 타일 | 고무 매트 | 계단 |
| 야시장 | 밤하늘, 네온, 전구줄 | 보도블록 · 물웅덩이 | 계단 |
| 쇼핑몰 | 쇼윈도 · 브랜드 간판 | 광택 대리석 | 에스컬레이터 |
| 오피스 | 창밖 야경, 파티션 책상 | 네이비 카펫 | 엘리베이터 문 |
| 루프탑 클럽 | 도시 야경, 유리 난간, 네온 | LED 격자 | 계단 |

- 부트스트랩은 `SchoolHallwayPrototypeBuilder.Build(floorCount, location.Id)`로 장소 맵을 짓는다.
- 인자 없는 `Build()`는 예전 학교 복도를 그대로 지어 기존 Unity 테스트를 유지한다.
