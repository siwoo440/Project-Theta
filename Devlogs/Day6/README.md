# Project θ 개발 일지 — 6일차

## 개발 목표

5일차까지 구현한 최면, 동행, 충동, 폭주 시스템을 실제 스테이지 진행 구조와 연결했다.

6일차 핵심 흐름은 다음과 같다.

```text
스테이지 시작
→ 제한시간 진행
→ NPC 최면
→ 동행 NPC 정기 생산
→ 충동 및 폭주 관리
→ 회수 지점 이용
→ 정기 200 달성 또는 실패 조건 판정
```

## 스테이지 진행 시스템

스테이지 상태를 관리하는 구조를 추가했다.

상태:

- Running
- Cleared
- FailedByTime
- FailedByHealth

초기 프로토타입 수치:

- 제한시간: 180초
- 목표 정기: 200
- 플레이어 최대 체력: 100

목표 정기 200에 도달하면 스테이지가 클리어된다.

제한시간이 0이 되거나 플레이어 체력이 0이 되면 실패 처리한다.

## 정기 시스템

정기를 얻는 경로를 세 가지로 구성했다.

### 동행 NPC 지속 생산

최면되어 Following 상태를 유지하는 NPC는 각자 정기를 생산한다.

```text
NPC 1명 = 초당 정기 +1
NPC 5명 = 초당 정기 +5
NPC 10명 = 초당 정기 +10
```

FollowerEssenceProducer가 각 NPC의 Following 상태를 확인하고 1초 간격으로 정기를 지급한다.

동행이 해제되거나 회수된 NPC는 생산을 중단한다.

## 회수 지점

학교 복도 오른쪽에 보라색 반투명 RecoveryPoint를 추가했다.

동행 NPC가 회수 지점에 진입하면 자동으로 회수된다.

회수 결과:

```text
Follower 목록에서 제거
→ Following 종료
→ NPC 비활성화
→ 정기 +5
```

회수 보상은 현재 +5로 설정했다.

RecoveryPoint 생성 과정에서 SpriteRenderer 누락으로 발생한 MissingComponentException을 수정했다.

현재는 SpriteRenderer를 RecoveryPoint보다 먼저 생성하고 RequireComponent로 필요한 컴포넌트를 보장한다.

## 플레이어 체력

PlayerHealth를 추가했다.

초기 수치:

- 최대 체력: 100
- 시작 체력: 100

현재 체력은 0~100 범위에서 관리된다.

체력이 0이 되면 StageState가 FailedByHealth로 전환된다.

## 폭주 피격 보상 및 피해

5일차 폭주 접촉 판정을 스테이지 자원과 체력 시스템에 연결했다.

폭주 NPC에게 잡히면:

```text
정기 +10
플레이어 HP -25
```

같은 한 번의 Rampage에서 접촉 보상과 피해가 중복 적용되지 않도록 1회 지급 플래그를 추가했다.

폭주가 종료되면 기존 Recovering 흐름으로 복귀한다.

## Follower 회수 처리

FollowerManager에 회수용 ConsumeFollower 경로를 추가했다.

기존 유지도 부족에 의한 일반 동행 해제와 회수 지점에 의한 NPC 소비를 별도 흐름으로 처리한다.

회수 후에는 남은 Follower 슬롯을 다시 정렬한다.

## HUD 개편

6일차 HUD를 실제 플레이 정보를 중심으로 재배치했다.

### 왼쪽 상단

플레이어 체력을 표시한다.

```text
HP 75 / 100
[체력 바]

폭주 피격: HP -25 / 정기 +10
```

체력 비율에 따라 체력 바가 감소한다.

### 중앙 상단

스테이지 핵심 목표 정보를 배치했다.

```text
남은 시간 02:31

정기 126 / 200
[정기 바]

지속 생산 +7 / sec | 회수 +5
```

정기 바는 CurrentEssence / TargetEssence 비율을 표시한다.

동행 인원에 따라 지속 생산량도 실시간으로 표시한다.

### 오른쪽 상단

개발 중 확인이 필요한 정보는 별도 Debug 영역으로 이동했다.

표시 항목:

- 동행 인원
- 최저 유지도
- 현재 최면 대상
- NPC 상태
- 최고 충동
- 현재 폭주 NPC
- 스테이지 상태
- 회수 지점 안내

## 테스트 항목

StageRules EditMode 테스트를 추가했다.

검증 항목:

- 정기 추가 및 목표값 Clamp
- 동행 인원에 따른 초당 생산량 계산
- 제한시간이 0 아래로 내려가지 않는지 확인
- 정기 목표 달성 시 Cleared 판정
- 시간 종료 시 FailedByTime 판정
- 체력 0 시 FailedByHealth 판정

## 6일차 완료 기준

다음 흐름을 기준으로 6일차 기능을 확인한다.

```text
TestStage 시작
→ 제한시간 180초
→ HP 100 / 100
→ 정기 0 / 200
→ NPC 최면 및 Following
→ NPC 수에 따라 정기 지속 생산
→ 폭주 NPC에게 잡힘
→ 정기 +10 / HP -25
→ 회수 지점에 NPC 진입
→ 정기 +5 / NPC 제거
→ 정기 200 달성
→ CLEAR
```

실패 조건:

```text
제한시간 0
→ FAILED - TIME

또는

HP 0
→ FAILED - HP
```
