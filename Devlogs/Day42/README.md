# 42일차 — 데이터 기반 스토리 진행 시스템 개편

## 구현

- 기존 장면 ID와 `SeenStories`를 유지하면서 시작·완료·진행 중 상태를 분리했다.
- 장면별 선택 결과를 저장하고 같은 장면의 선택을 최신 값으로 교체하도록 구현했다.
- 장소 진입·장소 클리어·허브 복귀·지도 진입·보스 승리·보스 패배 사건을 공용 대기열로 판정하도록 추가했다.
- 선행 장면 완료·선행 선택·장소 클리어·클리어 장소 수·엔딩 수·도시 지배도 조건을 조합할 수 있게 했다.
- 진행 중 장면을 같은 사건 흐름에서 우선 재개하고 완료 장면은 자동 재생에서 제외하도록 구현했다.
- 대사창에 선택지 버튼과 장면 시작·완료·선택 콜백을 추가했다.
- 자동 재생은 진행과 선택을 저장하고, 일기장 다시 보기는 저장 상태를 바꾸지 않도록 분리했다.
- 존재하지 않는 선행 장면, 중복 ID, 순환 선행 조건을 찾는 이야기 표 검증기를 추가했다.
- 저장 형식을 3버전으로 갱신하고 기존 `SeenStories`를 완료 장면으로 이관하도록 호환 처리를 추가했다.
