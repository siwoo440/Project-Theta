# Project θ 개발 일지 — 4일차

## 개발 목표

3일차에 구현한 최면 완료 상태를 실제 동행 시스템으로 연결하고, 여러 NPC가 플레이어를 자연스럽게 따라다닐 수 있도록 동행 관리 기능을 구현했다.

4일차 핵심 흐름은 다음과 같다.

```text
NPC 최면
→ 최면 100%
→ 동행 등록
→ Following 상태 전환
→ 플레이어 추적
→ 거리 및 유지도 관리
→ 자연스러운 군집 이동
```

## 최면 완료와 동행 연결

최면 수치가 100%에 도달하면 해당 NPC가 자동으로 FollowerManager에 등록되도록 연결했다.

최면 완료 NPC는 일반 Idle / Move / Alert 상태에서 빠져나와 Following 상태로 전환되며, 이후 FollowerController가 이동을 담당한다.

동행이 해제되면 최면 상태와 하트 표시가 초기화되고 일반 NPC 상태로 복귀한다.

## 동행 시스템

### FollowerManager

플레이어가 현재 동행 중인 NPC 목록을 관리한다.

주요 역할:

- 최면 완료 NPC 등록
- 동행 순서 관리
- NPC별 목표 위치 계산
- 동행 해제 처리
- 동행 해제 후 인덱스 재정렬
- 현재 동행 인원 HUD 제공

초기 구현의 최대 동행 4명 제한은 제거했다.

현재는 스테이지에 존재하는 NPC를 인원 제한 없이 동행시킬 수 있다.

## NPC 추적

FollowerController를 추가하여 최면 완료 NPC가 플레이어를 추적하도록 구현했다.

기본 수치:

- 기본 추적 속도: 5.0
- 따라잡기 거리: 4.0
- 따라잡기 속도: 7.0
- 기본 정지 거리: 0.14

플레이어와 일정 거리 이상 벌어지면 일반 추적보다 빠르게 따라잡는다.

## 최면 유지도

동행 NPC에 유지도 개념을 추가했다.

기본값:

- 최대 유지도: 100
- 거리 이탈 판정: 9.0
- 거리 초과 시 감소량: 초당 12
- 정상 거리 복귀 시 회복량: 초당 20

초기 감소량 35는 플레이 테스트에서 너무 빠르다고 판단하여 12로 낮췄다.

유지도가 0이 되면 NPC는 동행에서 이탈하고 일반 NPC 상태로 돌아간다.

HUD에서는 현재 동행자 중 가장 낮은 유지도를 확인할 수 있다.

## 최면 대상 방향 판정 개선

기존에는 플레이어가 바라보는 방향의 NPC만 최면 대상으로 선택할 수 있었다.

4일차에서는 이 제한을 제거했다.

현재 최면 대상 조건:

- 최면 가능 거리 안에 존재
- Y축 허용 범위 안에 존재
- 아직 최면 완료되지 않은 NPC

플레이어가 반대 방향을 보고 있더라도 NPC를 최면할 수 있다.

최면 대상이 선택되면 플레이어가 자동으로 해당 NPC 방향을 바라보도록 FaceToward 기능을 추가했다.

## 플레이어와 NPC 충돌

플레이어와 NPC가 서로 물리적으로 막지 않도록 충돌을 무시하도록 변경했다.

따라서 플레이어는 NPC와 겹쳐 지나갈 수 있으며, 동행 NPC가 플레이어 이동을 막지 않는다.

환경과의 충돌은 유지한다.

## NPC 간 Soft Separation

여학생 NPC끼리도 딱딱한 Collider 충돌로 서로 밀어내지 않도록 변경했다.

대신 너무 가까워졌을 때만 약한 보정 속도를 적용하는 Soft Separation 시스템을 추가했다.

기본값:

- 분리 기준 거리: 0.65
- 최대 분리 보정 속도: 0.9

결과적으로 NPC끼리 어느 정도 겹칠 수 있지만 완전히 같은 위치에 포개지는 현상은 감소한다.

## 자연스러운 동행 대열

초기 동행 구현에서는 NPC가 일정한 슬롯 위치를 사용하여 두 줄로 지나치게 정확하게 정렬되는 문제가 있었다.

이를 완화하기 위해 각 동행 NPC에 서로 다른 이동 특성을 추가했다.

### 개인 위치 편차

각 NPC는 동행 시작 시 자신만의 고정 위치 편차를 가진다.

- X축 편차: 약 ±0.38
- Y축 편차: 약 ±0.42

### 느린 위치 흔들림

동행 중 목표 위치가 완전히 고정되지 않도록 작은 주기 이동을 추가했다.

- X축 흔들림: 약 ±0.08
- Y축 흔들림: 약 ±0.11
- 흔들림 속도: NPC마다 서로 다르게 설정

### 이동 속도 차이

각 NPC의 추적 속도에 약 ±10% 차이를 둔다.

NPC마다 정지 거리도 약간 달라 같은 위치에서 동시에 멈추는 현상을 줄였다.

결과적으로 전체적으로는 플레이어 뒤를 따라오지만 완벽한 격자 대열이 아니라 약간 흐트러진 군집 형태로 움직인다.

## 최면 UI

최면 진행 중에는 NPC 아래 보라색 최면 게이지가 표시된다.

최면이 완료되면:

```text
보라색 게이지 숨김
→ 하트 아이콘 표시
→ Following 전환
```

동행이 해제되면 하트가 제거되고 최면 진행 상태도 초기화된다.

## HUD

4일차 HUD에 동행 상태를 추가했다.

표시 항목:

- 현재 동행 인원
- 동행자 중 최저 유지도
- 현재 최면 대상
- NPC 상태

최대 동행 제한을 제거했으므로 HUD에서도 현재 동행 인원만 표시한다.

## 코드 정리

프로토타입 진행 과정에서 더 이상 사용하지 않는 일부 코드와 임시 요소를 정리했다.

주요 정리 항목:

- RecoveryPointPlaceholder 생성 코드 제거
- RecoveryPoint 전용 Runtime Square 생성 코드 제거
- 사용하지 않는 HypnosisTarget.IsComplete 제거
- 사용하지 않는 FollowerController 공개 상태 프로퍼티 제거
- StopFollowing(bool) 분기를 StopFollowing()으로 단순화
- Unity 기본 SampleScene을 Build Settings에서 제거
- 오래된 테스트/중복 프로젝트 파일 정리

## 테스트

4일차에서 동행 관련 EditMode 테스트를 추가했다.

### Follower Formation

- 첫 번째/두 번째 슬롯 거리 계산
- 다음 열 거리 계산
- 상하 행 오프셋 계산

### Follower Stability

- 이탈 거리에서 유지도 감소
- 정상 거리에서 유지도 회복
- 0~최대값 Clamp

### NPC Soft Separation

- 완전히 겹친 경우 최대 분리 가중치
- 기준 거리 내부에서 부분 분리
- 기준 거리에서는 보정 없음
- 기준 거리 밖에서는 보정 없음

기존 NPC AI, 최면 대상 판정, 커서 애니메이션, 이동 및 Depth Sort 테스트도 유지한다.

## 4일차 완료 기준

다음 플레이 흐름을 기준으로 4일차 구현 완료 여부를 확인한다.

```text
NPC 발견
→ 방향과 관계없이 최면 가능
→ 플레이어가 대상 방향으로 자동 회전
→ 최면 100%
→ 하트 표시
→ NPC가 동행 시작
→ 여러 NPC 동행 가능
→ NPC가 플레이어와 겹쳐 이동 가능
→ NPC끼리 약간 겹치면서 너무 붙으면 자연스럽게 분리
→ NPC마다 조금씩 다른 위치와 속도로 따라옴
→ 멀어지면 유지도 감소
→ 다시 접근하면 유지도 회복
→ 유지도 0에서 동행 해제
```
