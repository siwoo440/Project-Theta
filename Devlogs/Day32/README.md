## A. 키 설정

### 입력을 한곳으로

그전에는 키를 직접 읽는 파일이 17개였고 입력 설정 파일(`ProjectInput.inputactions`)은 쓰이지 않았다.
게임 조작 8개 파일이 `GameInput`을 거쳐 읽도록 바꿨다.

| 파일 | 역할 |
| --- | --- |
| `Core/InputBindingLogic` | 조작 목록 · 기본 키표 · 겹침 검사 · 바꾸기 결과 · 저장 줄 · 키 이름 (순수 계산) |
| `Core/GameInput` | 현재 키표로 누름 · 방금 누름 · 이동 방향 읽기, 키 설정 창의 "새로 누른 키" 찾기 |

| 조작 | 기본 키 | 읽는 곳 |
| --- | --- | --- |
| 위 · 아래 · 왼쪽 · 오른쪽 이동 | W/↑ · S/↓ · A/← · D/→ | `PlayerSideViewController` |
| 대시 | Shift / Space | `PlayerSideViewController` |
| 층 이동 · 상호작용 | F | `FloorTransitionController` |
| 최면 (유지) | 마우스 왼쪽 | `HypnosisCaster`, `HypnosisCursorController` |
| 파동 (유지) | 마우스 오른쪽 | `HypnosisWaveCaster` |
| 탈출 · 힘겨루기 입력 A · B | 마우스 왼쪽 · 오른쪽 | `PlayerCaptureController`, `OpponentDuelController` |
| 아이템 1 · 2 | 1 · 2 | `PlayerConsumables` |

- 키는 글자로 저장한다. 키보드는 Input System 키 이름(`W`, `LeftShift`, `Digit1`), 마우스는 `Mouse0~2`.
- Esc · F1은 바꿀 수 없다.
- 디버그 패널 위 클릭 무시(`PointerGuard`)도 `GameInput`이 맡는다.
- 일시정지 · 설정 창에서 누른 클릭이 탈출 · 힘겨루기 입력으로 들어가지 않게 막았다.

### 저장

- `SaveData.KeyBindings`: `"MoveUp=W,UpArrow"` 줄들.
- 예전 세이브 · 모르는 키 이름 · 알 수 없는 조작은 기본 키로 채운다.
- 읽은 뒤 겹침이 남으면(손으로 고친 파일) 전체를 기본으로 되돌린다.
- `"7=Z"`처럼 숫자로 쓴 줄이 조작 번호로 읽히던 것을 테스트로 찾아 막았다.

### 설정 창

- 위에 `일반` · `키 설정` 탭. 31일차 설정은 `일반` 탭으로 옮겼다.
- 칸을 누르면 "키를 누르세요…" → 다음에 누른 키 · 마우스 버튼이 들어간다. 누른 프레임은 건너뛴다.
- Esc는 취소. 입력 대기 중에는 Esc 순서 맨 위에 대기 표식을 올려 창이 닫히지 않게 했다.
- 결과 문구: 성공(초록), 겹침 · 금지 키(빨강, 저장 안 함), 같은 키.
- 보조 칸 `×`로 비우기, `기본값으로 되돌리기`는 두 번 눌러야 된다.

### 안내 문구

계단 "[F] 2F로 올라가기", HUD "파동(우클릭 유지)", 붙잡힘 · 힘겨루기 입력 순서, 아이템 칸 글자, 튜토리얼 최면 안내가 현재 키를 표시한다.
조작법 창은 현재 키표를 읽고, 빠져 있던 **아이템 1 · 2** 줄을 넣었다. 화면 조작 줄에는 "(고정)"을 붙였다.

## C. 업적 46개

### 추가한 판정

| 판정 | 내용 |
| --- | --- |
| 새 통계 | 회수한 동행자 · 계약 정기 · 붙잡힘 · **빼앗김 없는 클리어 수**(`PlayStats.CleanClears`, 새로 셈) |
| 장소 기록 조합 | 90초 안에 클리어한 장소 수 · 지정 장소 S등급 · S등급 장소 수 |
| 장소 지정 | 업적 정의에 `Location`(장소 번호) 칸 |

### 분류별

| 분류 | 개수 | 보상 합계 | 새로 넣은 업적 |
| --- | ---: | ---: | --- |
| 도전 · 클리어 | 8 | 1,250 | 개근상 · 도시의 전설 · 무결점 · 번개 출근 |
| 장소 | 8 | 1,740 | 단골 거리 · 모범 연수생 · 루프탑의 주인 · 올 S |
| 엔딩 · 등급 | 5 | 1,420 | 영원한 밤 · 완벽의 경지 |
| 최면 · 동행 | 9 | 1,680 | 최면의 정점 · 대행렬 · 인도자 · 되찾은 사랑 |
| 정기 | 6 | 1,240 | 정기의 제왕 · 대박 · 계약 부자 |
| 위기 | 5 | 600 | 폭주 마스터 · 힘겨루기 챔피언 · 불굴 |
| 성장 · 시간 | 5 | 760 | 성장통 · 카드 도감 · 밤샘 근무 |
| **전체** | **46** | **8,690** | 기존 23개 2,690 + 새 23개 6,000 |

- 기존 업적 ID는 그대로라 달성 기록이 유지된다. 비슷한 업적끼리 붙도록 순서만 묶었다.
- 제안 단계에서 보상 합계를 2,990 + 5,550으로 잘못 계산했다가 테스트로 바로잡았다.
- 전체 목록(ID · 이름 · 조건 · 보상)은 기획서 부록용 표로 따로 정리했다.

### 업적 창

- 세 줄 배치(30일차 두 줄 → 한때 세 줄)를 **한 줄 목록 + 세로 스크롤**로 바꿨다.
- 한 줄: 이름 · 설명 · +보상 · 진행 막대 · "값 / 목표"(달성하면 금색 "달성", 보상 글자는 흐리게).
- `ScrollRect` + `RectMask2D` + 오른쪽 스크롤 막대. 휠 · 막대 끌기 · 목록 끌기. 열 때마다 맨 위.
- 방향키가 스크롤 막대로 가지 않게 했다.

## 알아 둘 것

- 기존 세이브로 시작하면 키 설정이 비어 기본값으로 시작하므로 **E 키로는 최면이 되지 않는다.** 최면 보조 칸에 E를 넣으면 된다.
- 아이템 칸 글자는 스테이지를 다시 들어가야 바뀐 키로 보인다.
- "번개 출근"(90초)은 지금 플레이 길이로는 바로 달성된다. 한 장소 플레이 길이를 조정하면 기준도 다시 본다.
